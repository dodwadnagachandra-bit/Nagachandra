Software Architecture — 5-Layer Module Stack
L5 APPLICATION LAYER
control_manager
Python • P0
1Hz control loop: safety → source priority (Day/Night) → mode → algorithm → derate → PCS setpoints
hmi_server
Python + React • P1
FastAPI + WebSocket. 7 screens. 1s telemetry push. Auth.
cloud_manager
Python • P1
paho-mqtt async. MQTT TLS. Telemetry + commands. Offline buffer.
diagnostics
Python • P2
SOH trend, PCS efficiency, thermal analysis, comm health.
ota_manager
Python • P2
A/B partition, signature verification, rollback, downstream FW.
◆ ZeroMQ PUB/SUB + REQ/REP — Inter-Module Communication ◆
L4 DATA LAYER
data_manager
C / Python • P0
POSIX shared memory RTDB. Auto-sized for 16S–108S topology. ZMQ pub on change.
config_manager
Python • P2
YAML/JSON config. Schema validation. Versioned. Backup/restore. Hot-reload support.
◆ POSIX Shared Memory (shm_open / mmap) — Real-Time Data Bus ◆
L3 SERVICE LAYER
alarm_manager
Python • P0
3-tier (E_W / A_P / P_P) per IEC 62682. Maps to DO-2/3/4 indicators.
safety_manager
C • P0
E-Stop, Fire, Flood. <100ms response. Hardware watchdog. Isolated process.
logger
C++ / Python • P1
Parquet 1Hz. DuckDB query. JSONL events. Configurable retention (90-day).
scheduler
Python • P1
Charge/discharge windows. 96-point curves. Hot-reload.
◆ ZeroMQ PUB/SUB — Event Bus (Alarms, State Changes) ◆
L2 COMMUNICATION LAYER
comm_manager
C (CAN) + Python (Modbus) • P0
Hybrid: C thread per cluster for SocketCAN RX/decode/RTDB write. Python orchestrator for Modbus RTU/TCP, lifecycle, health monitoring.
◆ Linux Kernel — SocketCAN / TTY / GPIO / Network ◆
L1 PLATFORM LAYER
Linux (Yocto / Ubuntu)
Kernel • System
SocketCAN, libgpiod, POSIX IPC, systemd, NTP, watchdog. TI AM6548 BSP.
POSIX shm + pthreads
C • System
shm_open, mmap for RTDB. RT priority threads for safety_manager.
libzmq
C • IPC
ZeroMQ message queues for all inter-module communication.
