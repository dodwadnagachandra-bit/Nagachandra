<objective>
Define all IPC contracts for the EMS: ZeroMQ socket paths, PUB/SUB topic strings, MessagePack payload schemas for three patterns (telemetry, commands, events), and prove C↔Python interoperability with mpack/msgpack roundtrip tests.

Purpose: Establishes the communication contract that all modules depend on. With RTDB structs (Phase 3) defining the data and IPC contracts (this phase) defining the messaging, modules can be developed independently against stable interfaces starting in M1.

Output: ipc_defs.h (C), ipc.py (Python), vendored mpack, C interop test, Python contract tests.
</objective>

**Schema helper functions:**

1. `encode_telemetry(timestamp_ms: int, seq: int, source: str, topic: str, payload: dict) -> bytes`
   - Packs a MessagePack map with envelope + payload
   - Uses `msgpack.packb()` with `use_bin_type=True`

2. `decode_telemetry(data: bytes) -> dict`
   - Unpacks a telemetry message, returns dict with envelope + payload
   - Uses `msgpack.unpackb()` with `raw=False`

3. `encode_command_request(action: str, params: dict) -> bytes`
   - Packs `{action: str, params: dict}`

4. `decode_command_request(data: bytes) -> tuple[str, dict]`
   - Returns `(action, params)`

5. `encode_command_response(status: str, result: dict | None = None, error_msg: str | None = None) -> bytes`
   - Packs `{status: "ok"|"error", result: {...}, error_msg: str|None}`

6. `decode_command_response(data: bytes) -> dict`
   - Returns dict with status, result, error_msg

7. `encode_event(timestamp_ms: int, source: str, severity: str, event_type: str, message: str, data: dict | None = None) -> bytes`
   - Packs structured event for PUSH/PULL

8. `decode_event(data: bytes) -> dict`
   - Returns dict with all event fields

All functions have return type annotations. Import msgpack at the top of the file.

   {
     "ts": 1234567890,        // uint64

     "src": "data_manager",   // string
     "topic": "pcs",          // string
     "payload": {             // nested map

       "active_power": 100.0, // float

   ```

   ```
   {

     "params": {

     }
   }
   ```

3. `encode_command_response_sample(mpack_writer_t *writer)` — Encode:
   ```
   {
     "status": "ok",
     "result": {
       "previous_mode": "idle"
     },
     "error_msg": null  // nil
   }
   ```

4. `encode_event_sample(mpack_writer_t *writer)` — Encode:
   ```
   {
     "ts": 1234567890,
     "src": "alarm_manager",

     "event_type": "alarm",

       "cell_id": 15,
       "voltage": 3.65
     }
   }

**Self-test mode (`--self-test`):**
- Encode each sample to a buffer using `mpack_writer_init_growable()`
- Decode each buffer using `mpack_reader_init_data()`
- Verify key fields match expected values using mpack reader API
- Print pass/fail for each message type
- Return 0 on all pass, 1 on failure

**Output mode (`--output <file>`):**
- Encode all 4 sample messages sequentially to the output file
- Each message is length-prefixed: 4-byte big-endian uint32 length followed by msgpack bytes
- This allows the Python test to read messages one at a time
- Print summary of bytes written

**`main()` function:**
- Parse argc/argv for `--self-test` or `--output <file>`
- Default to `--self-test` if no args
- Return 0 on success

Use Allman brace style. All mpack calls should check for errors via `mpack_writer_destroy()` and `mpack_reader_destroy()` return values.
