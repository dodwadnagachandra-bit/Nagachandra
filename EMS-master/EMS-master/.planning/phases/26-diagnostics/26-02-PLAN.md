  <name>Task 1: SohAnalyzer — BMS SOH trending and cycle detection</name>
  <files>
    src/diagnostics/src/ems_diagnostics/analyzers/__init__.py,

  <behavior>
    - SohAnalyzer(rack_id, rated_capacity_ah) initializes per-rack tracker
    - update(pack_i, pack_soc, pack_soh_bms) called at 1Hz updates internal state
    - Uses BMS-reported pack_soh as the primary SOH value for trending
    - Cycle detection: state machine (IDLE -> CHARGED -> DISCHARGING -> cycle complete)
      - IDLE -> CHARGED when pack_soc >= 90%
      - CHARGED -> DISCHARGING when pack_i < -0.5 (discharge current)
      - DISCHARGING -> IDLE when pack_soc <= 10% (cycle completes, count increments)
    - No double-counting: SOC oscillation near threshold does not re-trigger
    - Coulomb counting: accumulates abs(pack_i)/3600 during discharge phase for cross-validation
    - get_current() returns {"rack_id": int, "soh_pct": float, "cycle_count": int, "coulomb_soh_pct": float}
    - get_history() returns list of (timestamp, soh_pct) for trend queries
  </behavior>
  <action>
    1. Create src/diagnostics/src/ems_diagnostics/analyzers/__init__.py — import SohAnalyzer, PcsAnalyzer (PcsAnalyzer import can be deferred until Task 2).

    2. Create src/diagnostics/src/ems_diagnostics/analyzers/soh.py:
       - Class SohAnalyzer with __init__(rack_id: int, rated_capacity_ah: float)
       - Internal state: _state (IDLE/CHARGED/DISCHARGING), _cycle_count, _soh_pct, _cycle_ah, _history list
       - update(pack_i: float, pack_soc: float, pack_soh_bms: float) -> None:
         * Set _soh_pct = pack_soh_bms (BMS is primary per research Pitfall 4)
         * State machine for cycle detection (per research Pattern 5 and Pitfall 7)
         * Coulomb counting during DISCHARGING: _cycle_ah += abs(pack_i) / 3600.0
         * On cycle complete: compute coulomb_soh = (_cycle_ah / rated_capacity_ah) * 100, reset accumulator
       - get_current() -> dict: returns current SOH snapshot
       - add_history_point(timestamp_ms: int) -> None: appends (ts, soh_pct) to history (called by loop at trend interval)
       - get_history() -> list[tuple[int, float]]: returns SOH history points

    3. Create src/diagnostics/tests/test_soh_analyzer.py:
       - test_initial_state: fresh analyzer has soh=100, cycles=0
       - test_bms_soh_used_as_primary: after update with pack_soh=95.5, get_current()["soh_pct"] == 95.5
       - test_full_cycle_detection: simulate SOC going 50->90->50->10, verify cycle_count increments by 1
       - test_no_double_count_on_oscillation: SOC oscillates near 10% threshold, only one cycle counted
       - test_coulomb_counting_during_discharge: verify _cycle_ah accumulates correctly at 1Hz
       - test_get_current_structure: verify returned dict has rack_id, soh_pct, cycle_count keys
       - test_history_tracking: add_history_point appends to history, get_history returns list
  </action>

<task type="auto" tdd="true">
  <name>Task 2: PcsAnalyzer — AC/DC efficiency calculation</name>
  <files>
    src/diagnostics/src/ems_diagnostics/analyzers/pcs.py,
    src/diagnostics/tests/test_pcs_analyzer.py
  </files>
  <behavior>
    - PcsAnalyzer() initializes efficiency tracker
    - update(active_power, dc_voltage, dc_current) called at 1Hz
    - Computes dc_power = dc_voltage * dc_current
    - Skips calculation when abs(active_power) < IDLE_THRESHOLD_W (500W) or abs(dc_power) < IDLE_THRESHOLD_W
    - During discharge (active_power > 0): efficiency = abs(active_power) / abs(dc_power) * 100
    - During charge (active_power < 0): efficiency = abs(dc_power) / abs(active_power) * 100
    - Tracks rolling average efficiency over recent samples
    - get_current() returns {"efficiency_pct": float | None, "sample_count": int, "avg_efficiency_pct": float | None}
  </behavior>
  <action>
    1. Create src/diagnostics/src/ems_diagnostics/analyzers/pcs.py:
       - Class PcsAnalyzer with IDLE_THRESHOLD_W = 500.0
       - Internal state: _last_efficiency (float | None), _samples (collections.deque, maxlen=3600 for 1h of 1Hz), _sample_count
       - update(active_power: float, dc_voltage: float, dc_current: float) -> None:
         * Compute dc_power = dc_voltage * dc_current
         * If abs(active_power) < IDLE_THRESHOLD_W or abs(dc_power) < IDLE_THRESHOLD_W: set _last_efficiency = None, return
         * Discharge (active_power > 0): efficiency = abs(active_power) / abs(dc_power) * 100.0
         * Charge (active_power < 0): efficiency = abs(dc_power) / abs(active_power) * 100.0
         * Clamp to 0-100 range (guard against measurement noise giving >100%)
         * Store in _last_efficiency and append to _samples deque
       - get_current() -> dict: returns last efficiency, sample count, rolling average

    2. Update src/diagnostics/src/ems_diagnostics/analyzers/__init__.py to export PcsAnalyzer.

    3. Create src/diagnostics/tests/test_pcs_analyzer.py:

       - test_low_power_skipped: 200W AC, 300W DC returns None (below threshold)
       - test_discharge_efficiency: 9500W AC, 100V * 100A DC = 10000W DC -> 95.0%
       - test_charge_efficiency: -9500W AC (charging), 100V * -100A DC -> efficiency = 10000/9500 * 100 = ~105.3% clamped to 100
       - test_charge_efficiency_normal: -9000W AC, 100V * -100A = 10000W DC -> 10000/9000 * 100 = nah, charge eff = dc/ac = 10000/9000... Needs correct formula. For charge: useful output is stored energy (DC), input is grid (AC). So eff = abs(dc_power)/abs(ac_power). With -9000W AC and 10000W DC: 10000/9000 = 111% -> clamp to 100. Better test: -10000W AC, 9500W DC -> 9500/10000 = 95%.
       - test_rolling_average: multiple updates produce correct average
