  ```ini
  [Unit]
  Description=EMS Config Manager - Configuration Validation and Serving
  After=ems-data-manager.service
  Wants=ems-data-manager.service

  [Service]
  Type=simple
  ExecStartPre=/bin/mkdir -p /run/ems
  ExecStartPre=/bin/mkdir -p /var/lib/ems/config/backups
  ExecStart=/opt/ems/venv/bin/python -m ems_config_manager --config-dir /etc/ems/config --schema-dir /etc/ems/config/schemas
  Restart=always
  RestartSec=2
  User=ems
  Group=ems

  [Install]
  WantedBy=multi-user.target
  ```
  After=ems-data-manager.service because config_manager publishes events to ZMQ which data_manager's telemetry socket should be available for, though not strictly required (ZMQ tolerates late bind). Use Wants= (not Requires=) since config_manager CAN start without data_manager.
