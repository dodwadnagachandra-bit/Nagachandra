  <action>
    1. Create `lib/rolling-buffer.ts`:
       - `RollingBuffer<T>` class with constructor(maxSize: number)
       - `push(value: T): void` -- appends, shifts if over maxSize
       - `getAll(): T[]` -- returns shallow copy of buffer array
       - `clear(): void` -- empties buffer
       - `get length(): number` -- current size

    2. Create `hooks/useWebSocket.ts`:
       - `useWebSocket(url: string, dispatch: React.Dispatch<TelemetryAction>): ConnectionStatus`
       - Uses useEffect to create WebSocket connection
       - On open: set status "connected", reset retry counter to 0
       - On message: parse JSON as WsMessage, dispatch UPDATE_TOPIC action
       - On close: set status "disconnected", schedule reconnect with exponential backoff
       - Backoff: `Math.min(1000 * Math.pow(2, retries), 30000)` -- 1s, 2s, 4s, 8s, 16s, 30s cap
       - On error: let onclose handle reconnect (WebSocket fires close after error)
       - Cleanup: close WebSocket and clear timeout on unmount
       - Uses useRef for retry counter and WebSocket instance (not state -- avoids re-renders)
       - Uses useCallback for dispatch to avoid effect re-runs

    3. Create `context/TelemetryContext.tsx`:
       - `telemetryReducer` function implementing TelemetryAction handling:
         - "system" -> updates state.system
         - "pcs" -> state.pcs
         - "gpio" -> state.gpio
         - "meter" -> state.meter
         - "btms" -> state.btms
         - topics starting with "bms.rack." -> strip prefix, use as key in state.bmsRacks
         - All updates set lastUpdate to action.ts
       - `initialTelemetryState`: all nulls, empty bmsRacks, lastUpdate 0
       - `TelemetryContext` with value type `{ state: TelemetryState; connectionStatus: ConnectionStatus }`
       - `TelemetryProvider` component:
         - Creates useReducer with telemetryReducer
         - Determines WebSocket URL: in production use `ws://${window.location.host}/ws/telemetry`, in dev use relative `/ws/telemetry` (Vite proxy handles it)
         - Calls useWebSocket(url, dispatch) to get connectionStatus
         - Provides { state, connectionStatus } to children
       - Export `useTelemetryContext` hook that calls useContext(TelemetryContext) with error if outside provider

    4. Create `hooks/useTelemetry.ts`:
       - `useTelemetry(topic: "system"): SystemTelemetry | null` (overloads for each topic type)
       - Uses useTelemetryContext to access state
       - For "system", "pcs", "gpio", "meter", "btms" returns state[topic]
       - For BMS rack topics (e.g., "bms.rack.0.0") strips prefix and returns from bmsRacks map
       - Generic signature: `useTelemetry(topic: string): unknown`

    5. Write tests:
       - `RollingBuffer.test.ts`: push/getAll/clear/length, overflow behavior, empty buffer
       - `TelemetryContext.test.tsx`: reducer unit tests for each topic type, provider renders children
       - `useWebSocket.test.ts`: Mock WebSocket class globally. Test connect/dispatch/reconnect behavior. Verify backoff delays (1s, 2s, 4s, 8s, 16s, 30s).
  </action>
