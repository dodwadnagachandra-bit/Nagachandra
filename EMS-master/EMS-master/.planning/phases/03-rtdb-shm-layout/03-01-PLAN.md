<objective>
Define the complete RTDB shared memory layout as C headers with a seqlock concurrency primitive, Python ctypes mirror, and comprehensive tests. The RTDB is a single fixed-size struct (~1.8 MB at max topology) with compile-time array sizing, pre-aggregated data at every hierarchy level, and flat sections for non-BMS devices (PCS, GPIO, meter, BTMS).

Purpose: Establishes the data contract that all downstream modules (data_manager, comm_manager, safety_manager, control_manager, HMI) will share. The struct layout is the most coupled artifact in the system — getting it right now prevents painful refactors later.

Output: rtdb.h, seqlock.h, ems_common/rtdb.py (ctypes), C test, Python test, updated CMake/Makefile.

  <action>
Create `src/common/c/include/seqlock.h` — a self-contained, header-only seqlock implementation.

**Requirements:**
- Include guard: `#ifndef EMS_SEQLOCK_H` / `#define EMS_SEQLOCK_H`
- Include: `<stdatomic.h>`, `<stdbool.h>`, `<stdint.h>`
- C99 compatible (use `_Atomic` qualifier, not C11 `atomic_*` types where possible; `stdatomic.h` is available in C11 but GCC supports it in C99 mode)

**Struct:**
```c
typedef struct
{
    _Atomic uint32_t sequence;
} ems_seqlock_t;
```

**Inline functions (all `static inline`):**

1. `ems_seqlock_init(ems_seqlock_t *lock)` — Set sequence to 0.

2. `ems_seqlock_write_begin(ems_seqlock_t *lock)` — Increment sequence to odd (signals write in progress). Use `atomic_store_explicit(&lock->sequence, seq + 1, memory_order_release)`. Must also do a `atomic_thread_fence(memory_order_release)` after.

3. `ems_seqlock_write_end(ems_seqlock_t *lock)` — Increment sequence to even (signals write complete). Use `atomic_thread_fence(memory_order_release)` then `atomic_store_explicit(&lock->sequence, seq + 1, memory_order_release)`.

4. `ems_seqlock_read_begin(const ems_seqlock_t *lock)` — Returns uint32_t sequence value. Uses `atomic_load_explicit` with `memory_order_acquire`. If sequence is odd, spin until even (writer in progress). Add `atomic_thread_fence(memory_order_acquire)` after load.

5. `ems_seqlock_read_retry(const ems_seqlock_t *lock, uint32_t seq)` — Returns `bool`. Reads current sequence with acquire ordering, returns `true` if sequence changed (data was modified during read, must retry).

**Comments:**
- Doxygen block in .c style per CLAUDE.md (but since this is header-only, put Doxygen on each function)
- Comment explaining the odd/even protocol at the top of the file
- Comment: "Readers never block. Writers must be externally serialized (single-writer-per-section)."
- Comment all hardware register accesses (N/A here, but note the memory ordering choices)

**Allman brace style** per global preferences.

**Struct hierarchy (bottom-up, all with Allman braces):**

1. **`ems_module_t`** — Leaf node (per battery module / LMU):
   - `float cell_v[MAX_CELLS_PER_MODULE]` — Cell voltages (V)
   - `float cell_t[MAX_TEMPS_PER_MODULE]` — Temperature readings (°C)
   - `uint8_t balancing[MAX_CELLS_PER_MODULE]` — Per-cell balancing active flag (0/1)

2. **`ems_rack_t`** — One BMU rack:
   - `ems_seqlock_t lock` — Seqlock for this rack's data
   - `uint64_t last_update_ms` — Monotonic timestamp of last update (CLOCK_MONOTONIC ms)
   - `ems_module_t modules[MAX_MODULES_PER_RACK]` — Module array
   - Pack-level aggregates (all `float`):
     - `pack_v` (V), `pack_i` (A), `pack_soc` (%), `pack_soh` (%)
     - `min_cell_v`, `max_cell_v`, `avg_cell_v` (V)
     - `min_cell_t`, `max_cell_t`, `avg_cell_t` (°C)
   - `uint32_t fault_code` — BMS fault bitmap
   - `uint8_t online` — Rack communication status (0=offline, 1=online)

3. **`ems_cluster_t`** — Group of racks on one CAN bus:
   - `ems_rack_t racks[MAX_RACKS_PER_CLUSTER]` — Rack array
   - Cluster aggregates (same pattern as rack): `cluster_v`, `cluster_i`, `cluster_soc`, `cluster_soh`, min/max/avg cell_v, min/max/avg cell_t (all `float`)

4. **`ems_pcs_t`** — PCS inverter telemetry:
   - `ems_seqlock_t lock`
   - `uint64_t last_update_ms`
   - `float ac_voltage` (V), `ac_current` (A), `active_power` (kW), `reactive_power` (kVAR)
   - `float dc_voltage` (V), `dc_current` (A)
   - `float frequency` (Hz), `temperature` (°C)
   - `ems_pcs_state_t state`
   - `uint32_t fault_code`

5. **`ems_gpio_t`** — Safety digital I/O:
   - `ems_seqlock_t lock`
   - `uint64_t last_update_ms`
   - `uint8_t di[8]` — Digital inputs (0=open, 1=closed)
   - `uint8_t do_state[8]` — Digital outputs (named `do_state` because `do` is a C keyword)

6. **`ems_meter_t`** — Energy meter readings:
   - `ems_seqlock_t lock`
   - `uint64_t last_update_ms`
   - `float voltage` (V), `current` (A), `active_power` (kW), `reactive_power` (kVAR)
   - `float frequency` (Hz), `power_factor`
   - `float energy_import` (kWh), `energy_export` (kWh)

7. **`ems_btms_t`** — Battery thermal management (per rack):
   - `ems_seqlock_t lock`
   - `uint64_t last_update_ms`
   - `float inlet_temp` (°C), `outlet_temp` (°C)
   - `float fan_speed_pct` (%)
   - `uint8_t cooling_active`

8. **`ems_system_t`** — System-level aggregates and control state:
   - `ems_seqlock_t lock`
   - `uint64_t last_update_ms`
   - `ems_control_state_t control_state`
   - `ems_source_priority_t source_priority`
   - `float active_setpoint_kw` (kW)
   - `float total_soc` (%), `total_power_kw` (kW), `total_energy_kwh` (kWh)
   - `uint32_t ems_uptime_s` (seconds)

9. **`ems_rtdb_t`** — Top-level RTDB container:
   - `uint32_t magic` — Must be RTDB_MAGIC (0x454D5352)
   - `uint32_t version` — Must be RTDB_VERSION
   - `uint8_t cluster_count` — Active clusters (from config)
   - `uint8_t racks_per_cluster` — Active racks per cluster (from config)
   - `uint8_t modules_per_rack` — Active modules per rack (from config)
   - `uint8_t cells_per_module` — Active cells per module (from config)
   - `uint8_t temps_per_module` — Active temps per module (from config)
   - `uint8_t _pad[3]` — Alignment padding
   - `ems_cluster_t clusters[MAX_CLUSTERS]`
   - `ems_pcs_t pcs`
   - `ems_gpio_t gpio`
   - `ems_meter_t meter`
   - `ems_btms_t btms`
   - `ems_system_t system`

 * RTDB Memory Layout — compile-time max arrays
