    - query_latest(data_dir, signals, file_prefix) returns single most recent row
    - query_range_stats(data_dir, signals, start_ts, end_ts, file_prefix) returns min/max/avg/count per signal
    - query_event_log(data_dir, start_ts, end_ts, severity_filter, source_filter, limit) reads JSONL files and filters
    - query_energy_totals(data_dir, start_ts, end_ts) returns charge_kwh, discharge_kwh, grid_import, grid_export
    - query_cell_snapshot(data_dir, cluster, rack, timestamp) returns all cell voltages + temps at nearest second
    - All queries use in-memory duckdb.connect() -- no persistent database
    - Date-narrowed glob patterns to avoid scanning all 90 days for short time ranges
  </behavior>
  <action>
    Create query_handler.py with query functions:

    1. _build_date_glob(data_dir, start_ts, end_ts, prefix) -> list[str]:
       Build narrowed glob patterns from time range. For single-day queries use data_dir/{year}/{month:02d}/{day:02d}/{prefix}*.parquet. For multi-day, generate per-day globs. Fall back to broad glob for >30 day ranges.

    2. query_time_series(data_dir, signals, start_ts, end_ts, interval_s, file_prefix="telemetry_*"):
       Use DuckDB time_bucket() for downsampling. avg() aggregation per signal. LIMIT 10000.
       Use parameterized WHERE ts >= ? AND ts <= ?.

    3. query_latest(data_dir, signals, file_prefix="telemetry_*"):
       ORDER BY ts DESC LIMIT 1 from most recent day's files.

    4. query_range_stats(data_dir, signals, start_ts, end_ts, file_prefix="telemetry_*"):
       SELECT min(s), max(s), avg(s), count(*) for each signal.

    5. query_event_log(data_dir, start_ts, end_ts, severity_filter=None, source_filter=None, limit=1000):
       Read JSONL files in date range using JsonlEventWriter.read_events(). Filter in Python (JSONL files are small). Return list of event dicts.

    6. query_energy_totals(data_dir, start_ts, end_ts):
       Sum positive pcs_active_power as discharge, negative as charge. Sum meter_energy_import/export deltas.

    7. query_cell_snapshot(data_dir, cluster, rack, timestamp):
       Find nearest row by ts in cluster file, extract cell_v and cell_t LIST columns for specified rack.
