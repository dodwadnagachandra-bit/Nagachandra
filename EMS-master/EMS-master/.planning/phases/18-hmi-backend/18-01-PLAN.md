    - Test: Protected endpoint without token returns 401

  <action>
    1. **auth.py** — Create APIRouter with prefix="/api/auth", tag="auth":
       - `TokenStore` class (or use the dict on app.state directly):
         - `tokens: dict[str, dict]` where value is `{"level": str, "expires_at": float}`
         - `create_token(level: str, timeout_s: int) -> str` — generates `secrets.token_hex(32)`, stores with expiry, returns token. If len(tokens) >= 10, clean expired first, then reject with 429 if still >= 10.
         - `validate_token(token: str) -> dict | None` — returns level dict if valid and not expired, else None. Removes if expired (lazy cleanup).
         - `remove_token(token: str) -> bool` — removes token, returns True if existed.
         - `cleanup_expired() -> int` — removes all expired tokens, returns count removed.

       - POST `/login` endpoint:
         - Accepts `LoginRequest` body (pin field).
         - Reads operator_pin_hash and admin_pin_hash from `request.app.state.config["auth"]`.
         - Checks operator PIN first, then admin PIN. If admin PIN matches, admin level wins (overrides operator). Use `bcrypt.checkpw(pin.encode("utf-8"), hash.encode("utf-8"))`.
         - If match: create token via TokenStore, return `LoginResponse`.
         - If no match: raise HTTPException(401, detail="Invalid PIN").

       - POST `/logout` endpoint:
         - Requires valid auth (uses `require_auth` dependency).
         - Removes token from store.
         - Returns `MessageResponse(message="Logged out")`.

    2. **app.py** — Update `create_app` to:
       - Initialize `app.state.token_store` as a `TokenStore` instance (not raw dict).
       - Include auth router.
       - Start a background task in lifespan that runs `token_store.cleanup_expired()` every 60 seconds. Cancel on shutdown.

    3. **test_auth.py** — Comprehensive auth tests (10+ tests covering all behaviors above). Use the `async_client` fixture from conftest. For expired token tests, create a token and then manually set its expires_at to the past in the token store.
