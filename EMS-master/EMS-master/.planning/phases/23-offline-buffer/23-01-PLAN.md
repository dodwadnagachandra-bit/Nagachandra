  <action>
    Create `src/cloud_manager/src/ems_cloud_manager/buffer.py` implementing `BufferManager`:

    **Class design (per research recommendation):**
    - `__init__(self, buffer_dir: Path, max_hours: int, max_mb: int)` — stores config, calls `buffer_dir.mkdir(parents=True, exist_ok=True)`, initializes `_writes_since_sync = 0`, `_current_file: IO[str] | None = None`, `_current_hour_key: str = ""`
    - `write(self, msg_type: str, topic: str, payload: dict[str, Any]) -> None` — enforce retention first, then build record `{"ts": time.time(), "type": msg_type, "topic": topic, "payload": payload}`, open/rotate hourly file if needed, `json.dumps(record) + "\n"`, increment `_writes_since_sync`, fsync every 100 writes (use `_SYNC_EVERY = 100` constant). If retention says drop, log WARNING and return.
    - `drain(self) -> Iterator[tuple[Path, list[dict[str, Any]]]]` — yield `(file_path, records)` for each file sorted oldest-first. Caller deletes after consuming. Skip currently-open file by `_current_hour_key` check. Read each line with `json.loads()`, skip `json.JSONDecodeError` lines (crash recovery per CONTEXT.md).
    - `flush(self) -> None` — if `_current_file` is open, flush + fsync + close it, reset `_current_hour_key` so next write opens a new handle.
    - `_enforce_retention(self) -> None` — get all files sorted oldest-first, delete files with path-date older than `max_hours` (using `_file_datetime_from_path`), then delete oldest files until `_total_size_mb() <= max_mb`. Remove empty parent dirs after each deletion (up to `_buffer_dir`).
    - `_total_size_mb(self) -> float` — `sum(f.stat().st_size for f in self._all_files_sorted()) / (1024 * 1024)`
    - `_all_files_sorted(self) -> list[Path]` — `sorted(self._buffer_dir.rglob("cloud_*.jsonl"), key=lambda p: p.as_posix())`
    - `_current_file_path(self) -> Path` — derive from UTC `datetime.now(timezone.utc)`: `buffer_dir/YYYY/MM/DD/cloud_HH.jsonl`
    - `_file_datetime_from_path(self, path: Path) -> datetime | None` — extract year/month/day from parent dirs, hour from `cloud_HH` stem. Return None on parse failure.
    - `_remove_empty_parents(self, path: Path) -> None` — walk up from `path.parent` to `self._buffer_dir`, remove empty dirs.
    - `stats` property — returns `{"files_remaining": len(files), "mb_remaining": round(total_mb, 2)}`

    **File rotation:** Track `_current_hour_key` as `"YYYY-MM-DD-HH"`. On each write, compute current hour key. If different from stored key, close old file, open new one. Create parent dirs with `mkdir(parents=True, exist_ok=True)`.

    **Tests in `tests/test_cloud_manager.py`:** Add a `class TestBufferManager` section at the end of the file. All tests use `tmp_path` fixture for the buffer directory. Use `freezegun` or manual time mocking for hour-rotation and age-based retention tests. If `freezegun` is not available, use `unittest.mock.patch("time.time")` and `unittest.mock.patch("ems_cloud_manager.buffer.datetime")` to control timestamps.

    **Anti-patterns to avoid per research:**
    - Do NOT fsync every write — use `_SYNC_EVERY = 100` (matches logger pattern)
    - Do NOT use line-level deletion — file-level only (delete whole file after full drain)
    - Do NOT use `os.path.getmtime()` for age — extract from path components (mtime unreliable across copies)
    - Do NOT check retention during replay — only during writes (replay only decreases size)
