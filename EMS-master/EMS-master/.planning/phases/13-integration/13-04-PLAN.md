**RECOVERY_TIMEOUT_S = 10.0** -- maximum allowed recovery time per CONTEXT.md.

- Call `module.restart()`
- Use `wait_for_criteria` with checks:

- Assert all criteria met
- Return elapsed time

**Class TestSingleModuleCrashRecovery:**

This tests each module individually. The test needs a running system as baseline.

Fixture `running_system` (class scope): Launch all modules in order (same as startup test). Yield dict of name -> ModuleProcess. Teardown: cleanup all.

**Parametrized tests** -- use `@pytest.mark.parametrize("module_name,signal_num", [...])` to test each module with both SIGKILL and SIGTERM:

Parametrize list:
```python
CRASH_MATRIX = [

    ("config_manager", signal.SIGTERM),
    ("data_manager_python", signal.SIGKILL),

    ("comm_manager_python", signal.SIGKILL),
```

Test method `test_module_crash_recovery(self, running_system, module_name, signal_num)`:
1. Get module from running_system dict. Skip if module was not started (None).
2. Assert module is currently alive (precondition).
3. Record original PID.
4. Kill module with specified signal: `module.kill(sig=signal_num)`
5. Wait briefly for process to die: assert `not module.is_alive` within 2 seconds.
6. Call `module.restart()`.
7. Use `wait_for_criteria` with timeout=RECOVERY_TIMEOUT_S:
   - `"alive"`: module.is_alive
   - `"rtdb_fresh"`: check_rtdb_fresh() (for modules that write RTDB)
8. Assert all criteria True. Assert new PID != original PID.
9. Assert elapsed time < RECOVERY_TIMEOUT_S.

Test method `test_rtdb_survives_data_manager_crash(self, running_system)`:
1. Get data_manager_c module. Skip if not available.
2. Attach to RTDB, read magic and version, detach.
3. Kill data_manager_c with SIGKILL.
4. Wait for process to die.
5. Assert `/dev/shm/ems_rtdb` still exists (shm survives process death).
6. Attach to RTDB again -- assert magic and version unchanged (no corruption).
7. Restart data_manager_c.
8. Assert recovery within 10 seconds.

**Class TestDoubleFault:**

Fixture `running_system` (class scope): Same as above (or shared).

Test method `test_comm_and_logger_double_fault(self, running_system)`:
1. Get comm_manager_python and logger modules. Skip if either unavailable.
2. Kill both simultaneously with SIGKILL.
3. Wait for both to die.
4. Restart both (comm first, then logger -- mimics systemd ordering).
5. Assert both recover within 10 seconds.
6. Verify RTDB still valid (attach, check magic, detach).
7. If safety_manager is running, verify it's still alive (unaffected by comm+logger crash).

Test method `test_safety_gpio_continuity_during_restart(self, running_system)`:
1. Get safety_manager module. Skip if not available.
2. Skip if GPIO harness RTDB backend is not available.
3. Using GPIO harness RtdbBackend, set DI state to trigger E-Stop (DI-6=1 active, DI-7=0 NC broken).
4. Wait for safety_manager to assert safety outputs (DO-0, DO-4, DO-5, DO-6).
5. Verify DO pins are asserted (precondition).
6. Start a tight polling loop on DO-0 in a background thread (sample every 1ms with time.monotonic timestamps).
7. Kill safety_manager with SIGKILL.
8. Immediately restart safety_manager.
9. Wait for safety_manager to recover (is_alive within 10s).
10. Stop the polling loop.
11. Analyze collected DO-0 samples: assert DO-0 was NEVER de-asserted (value never went to 0) during the restart gap.
12. This validates CONTEXT.md: "Safety outputs remain asserted during safety_manager restart gap -- verify no gap in GPIO"
Note: On dev machines without real GPIO, safety outputs are stored in RTDB safety_state DO fields. The GPIO harness RtdbBackend can read these. If neither GPIO nor RTDB backend is available, skip this test.

Test method `test_data_manager_and_comm_double_fault(self, running_system)`:
1. Get data_manager_c and comm_manager_python modules. Skip if either unavailable.
2. Kill both simultaneously with SIGKILL.
3. Restart data_manager_c FIRST (it owns RTDB).
4. Wait for data_manager_c to be alive and RTDB to exist.
5. Then restart comm_manager_python.
6. Assert both recover within 10 seconds.
7. Verify RTDB valid.

**Important implementation notes:**
- Since tests use subprocess.Popen (not systemd), the TEST acts as the restart agent. After killing a process, the test calls `module.restart()` to simulate systemd's Restart=always.
- Use `time.monotonic()` for all timing measurements.
- The `running_system` fixture should skip gracefully if C binaries not built or vcan0 unavailable -- populate the dict with None for unavailable modules.
- For C modules, add them to CRASH_MATRIX only if the running_system fixture started them. Use `pytest.param(..., marks=pytest.mark.skipif(...))` or check at runtime.
- RTDB corruption check: attach_rtdb succeeds and magic == RTDB_MAGIC and version == RTDB_VERSION.
- After each crash test, give a 1-second buffer before next test to avoid port/socket conflicts.
