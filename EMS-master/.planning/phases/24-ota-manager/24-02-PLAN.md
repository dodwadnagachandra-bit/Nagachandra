    1. Create health.py (src/ota_manager/src/ems_ota_manager/health.py):
       - class HealthChecker:
         - __init__(self, services: list[str], timeout_s: float = 300.0, poll_interval_s: float = 10.0)
         - async check_services_active(self) -> tuple[bool, list[str]] — returns (all_active, list_of_failed_services). Uses asyncio.create_subprocess_exec("systemctl", "is-active", f"{svc}.service") for each service.

    2. Create state_machine.py (src/ota_manager/src/ems_ota_manager/state_machine.py):
       - class OtaState(str, Enum): IDLE, DOWNLOADING, VERIFYING, APPLYING, REBOOTING, ROLLED_BACK
       - class VersionState: Pydantic BaseModel or dataclass with current: str, previous: str. Loaded from / saved to JSON file (path from config.version.state_path). Atomic write.
       - class OtaStateMachine:
         - __init__(self, downloader: HttpDownloader, verifier: PackageVerifier, partition: PartitionBackend, health_checker: HealthChecker, version_state_path: Path, on_state_change: Callable[[OtaState, dict], None] | None = None)
         - state: OtaState property (read-only)
         - version_state: VersionState property
         - async start_update(self, notification: dict) -> None
           - notification has: {version, url, sha256, size_bytes}
           - Validates not already updating (state must be IDLE)
           - Sets state to DOWNLOADING, calls downloader.download(url, "package.tar", sha256, on_progress=self._on_download_progress)
           - Sets state to VERIFYING, calls verifier.extract_package, verifier.verify_manifest, verifier.verify_firmware_hash, verifier.check_min_version
           - Sets state to APPLYING, calls partition.write_image_to_standby, then swap boot flag (set active=standby, previous=current_active, boot_count=0, pending_health_check=True), then partition.write_boot_flag
           - Sets state to REBOOTING, saves version_state (current=new_version, previous=old_version), calls partition.reboot
         - async check_post_boot_health(self) -> None
           - Called on startup if boot flag has pending_health_check=True
           - Runs health_checker.run_health_check()
           - If healthy: clear pending_health_check in boot flag, set state to IDLE
           - If timeout: rollback — revert boot flag (active=previous, previous=active), set pending_health_check=False, set state to ROLLED_BACK, revert version_state, reboot
         - async do_manual_rollback(self) -> None
           - Same as health check timeout path but explicitly triggered
         - _set_state(self, new_state: OtaState, detail: dict | None = None) -> None — updates state, calls on_state_change callback

       - Each state transition wrapped in try/except — any failure during DOWNLOADING/VERIFYING/APPLYING cleans up staging and returns to IDLE with error detail in on_state_change callback.

  <action>
    1. Create loop.py (src/ota_manager/src/ems_ota_manager/loop.py):
       - class OtaManager:
         - __init__(self, config: dict, state_machine: OtaStateMachine, partition: PartitionBackend, ota_pub_endpoint: str | None = None, ota_cmd_endpoint: str | None = None)
         - stop_event: asyncio.Event
         - _zmq_ctx: zmq.asyncio.Context
         - _ota_pub: zmq.asyncio.Socket (PUB, bind to ota_pub_endpoint or SOCK_OTA_PUB)
         - _ota_rep: zmq.asyncio.Socket (REP, bind to ota_cmd_endpoint or SOCK_OTA_CMD)
         - _seq: int = 0

         - async run(self) -> None:
           - Check boot flag for pending_health_check — if True, run state_machine.check_post_boot_health()
           - Publish initial IDLE status
           - Start concurrent tasks: _command_loop(), _status_publish_loop()
           - Wait for stop_event
           - Cancel tasks, cleanup sockets

         - _on_state_change(self, new_state: OtaState, detail: dict | None = None) -> None:
           - Build telemetry payload: {state, version_current, version_previous, detail, ts}
           - encode_telemetry(ts, seq, "ota_manager", TOPIC_OTA, payload)
           - send_multipart([TOPIC_OTA.encode(), body], flags=zmq.NOBLOCK)

         - async _command_loop(self) -> None:
           - NOBLOCK recv on _ota_rep, decode_command_request
           - Actions: "get_version" -> return current/previous from state_machine.version_state
           - Actions: "rollback" -> asyncio.create_task(state_machine.do_manual_rollback())
           - Actions: "start_update" -> params has {version, url, sha256, size_bytes}, asyncio.create_task(state_machine.start_update(params))
           - Unknown action -> error response
           - Sleep 0.05s between polls (same pattern as cloud_manager)

         - async _status_publish_loop(self) -> None:
           - Every 5s (configurable from config.download.progress_interval_s), publish current state on ZMQ PUB
           - Only during active update states (DOWNLOADING, VERIFYING, APPLYING); skip in IDLE to reduce noise

         - def cleanup(self) -> None: close ZMQ sockets + context

       - Pass self._on_state_change as the on_state_change callback to OtaStateMachine.
