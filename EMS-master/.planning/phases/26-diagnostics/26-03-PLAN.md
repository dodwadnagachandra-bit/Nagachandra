  <name>Task 1: ThermalAnalyzer — cooling effectiveness and fan duty</name>
  <files>
    src/diagnostics/src/ems_diagnostics/analyzers/thermal.py,

  </files>
  <behavior>
    - ThermalAnalyzer() tracks cooling effectiveness metrics
    - update(max_cell_t, outlet_temp, fan_speed_pct) called at 1Hz from BMS + BTMS telemetry
    - delta_t = max_cell_t - outlet_temp (NOT ambient_temp — Pitfall 5: no ambient sensor in BTMS)
    - Fan duty score = rolling average of fan_speed_pct (collections.deque, maxlen for 1h of data)
    - get_current() returns {"delta_t": float, "fan_duty_score": float, "max_cell_t": float, "outlet_temp": float}
    - Handles missing data gracefully (None values before first update)
  </behavior>
  <action>
    1. Create src/diagnostics/src/ems_diagnostics/analyzers/thermal.py:
       - Class ThermalAnalyzer
       - Internal state: _delta_t (float | None), _max_cell_t (float | None), _outlet_temp (float | None), _fan_samples (collections.deque maxlen=3600)
       - update(max_cell_t: float, outlet_temp: float, fan_speed_pct: float) -> None:
         * _delta_t = max_cell_t - outlet_temp
         * _max_cell_t = max_cell_t
         * _outlet_temp = outlet_temp
         * Append fan_speed_pct to _fan_samples
       - get_current() -> dict:
         * fan_duty_score = mean of _fan_samples if non-empty, else None
         * Return delta_t, fan_duty_score, max_cell_t, outlet_temp

    2. Create src/diagnostics/tests/test_thermal_analyzer.py:
       - test_initial_state_none: before any update, get_current() returns None values
       - test_delta_t_calculation: max_cell_t=35.0, outlet_temp=25.0 -> delta_t=10.0
       - test_fan_duty_score: multiple updates with fan_speed_pct values -> correct average
       - test_negative_delta_t: outlet_temp > max_cell_t -> negative delta (valid scenario during cooling)
       - test_get_current_structure: verify all expected dict keys present
       - test_rolling_window: more than maxlen samples -> oldest dropped, average still correct
  </action>
  <verify>
    <automated>uv run pytest src/diagnostics/tests/test_thermal_analyzer.py -x -q</automated>
  </verify>
  <done>ThermalAnalyzer computes delta_t from cell temp - outlet temp, tracks fan duty rolling average. 6+ tests pass.</done>
</task>

<task type="auto" tdd="true">
  <name>Task 2: CommAnalyzer — device fault frequency scoring</name>
  <files>
    src/diagnostics/src/ems_diagnostics/analyzers/comm.py,
    src/diagnostics/tests/test_comm_analyzer.py
  </files>
  <behavior>
    - CommAnalyzer(known_devices) initializes with list of expected device IDs
    - update_from_event_log(event_rows: list[dict]) processes logger query results
    - Counts comm_fault events per device_id from event rows
    - Computes fault_rate = faults / hour for each device
    - Devices with no faults get fault_rate = 0 (healthy)
    - Devices not in known_devices but in events are included (unexpected device)
    - get_current() returns list of {"device_id": str, "fault_count": int, "fault_rate_per_hour": float, "status": str}
    - Status: "healthy" (0 faults), "degraded" (> 0 but < warning_rate), "unhealthy" (>= warning_rate)
  </behavior>
  <action>
    1. Create src/diagnostics/src/ems_diagnostics/analyzers/comm.py:
       - Class CommAnalyzer with __init__(known_devices: list[str], warning_rate: int = 5)
       - _known_devices: set of device IDs (e.g., ["bms_rack_0", "pcs", "btms", "meter"])
       - _fault_counts: dict[str, int] — reset on each update_from_event_log call
       - _query_window_hours: float — set by update call (default 1.0)
       - update_from_event_log(event_rows: list[dict], window_hours: float = 1.0) -> None:
         * Reset _fault_counts to {dev: 0 for dev in _known_devices}
         * For each row where event_type == "comm_fault": increment _fault_counts[device_id]
         * Store window_hours for rate calculation
       - get_current() -> list[dict]:
         * For each device in _fault_counts: compute fault_rate = count / window_hours
         * Determine status based on fault_rate vs warning_rate threshold
         * Return sorted list of device dicts

    2. Update src/diagnostics/src/ems_diagnostics/analyzers/__init__.py to export ThermalAnalyzer and CommAnalyzer.

    3. Create src/diagnostics/tests/test_comm_analyzer.py:
       - test_no_faults_all_healthy: empty event rows -> all known devices at fault_rate=0, status="healthy"
       - test_fault_counting: events with 3 pcs faults, 1 btms fault -> correct counts
       - test_fault_rate_calculation: 6 faults in 2-hour window -> rate = 3.0/hour
       - test_status_thresholds: 0=healthy, 3=degraded (< 5 warning), 5=unhealthy (>= 5 warning)
       - test_unknown_device_included: device not in known_devices appears in events -> included in results
       - test_get_current_structure: verify list of dicts with correct keys
       - test_update_resets_counts: two consecutive updates -> second replaces first (no accumulation)
  </action>
