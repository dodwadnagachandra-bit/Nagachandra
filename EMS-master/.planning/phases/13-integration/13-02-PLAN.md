**Class TestStartupSequence:**

Fixture `all_modules` (class scope): Launches all modules in order using ModuleProcess. Yields list of ModuleProcess instances. Teardown: cleanup all in reverse order. Skip CAN-dependent modules if vcan0 unavailable. Skip safety_manager if binary not found or no GPIO sim available.

Test methods:
1. `test_all_modules_start_within_30s(self, all_modules)`: Assert that launching all modules and reaching readiness takes < 30 seconds total. Record start time before first launch, check all `is_alive` after last launch. Assert elapsed < 30s.

2. `test_rtdb_valid_after_startup(self, all_modules)`: After all modules up, attach to RTDB via `attach_rtdb()`, validate magic and version match expected values. Detach cleanly.
