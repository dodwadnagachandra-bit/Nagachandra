**Class ModuleProcess:**
- `__init__(self, name: str, cmd: list[str], ready_check: Callable[[], bool], env: dict[str, str] | None = None) -> None`
  - Stores name, cmd, ready_check, env
  - Sets `self.proc: subprocess.Popen | None = None`
  - Calls `self.start()`
- `start(self) -> None`
  - Launches subprocess with `subprocess.Popen(cmd, stdout=PIPE, stderr=PIPE, env={**os.environ, **(env or {})}, preexec_fn=os.setpgrp)`
  - Calls `_wait_ready()`
- `_wait_ready(self, timeout: float = 15.0) -> None`
  - Uses `time.monotonic()` deadline loop with 0.2s sleep
  - Raises `TimeoutError(f"{self.name} not ready within {timeout}s")`
- `restart(self) -> None`
  - Terminates existing proc if alive, then calls `start()`
- `kill(self, sig: int = signal.SIGKILL) -> None`
  - Sends signal, waits up to 5s
- `terminate(self) -> None`
  - Sends SIGTERM, waits 5s, falls back to SIGKILL
- `pid` property: returns `self.proc.pid`
- `rss_bytes` property: uses `psutil.Process(self.proc.pid).memory_info().rss`, returns 0 on NoSuchProcess
- `is_alive` property: returns `self.proc.poll() is None`
- `cleanup(self) -> None`: terminate if alive, then try `os.killpg` for process group cleanup
