1. Create orchestrator.py with CommOrchestrator class:
   - Constructor: `__init__(self, devices: list[ModbusDevice], push_socket: zmq.Socket):`
     - Groups devices by port (devices on same serial port poll sequentially)
     - Sorts devices within each port group by priority (lower = higher priority)
   - `async def run(self) -> None`:
     - Creates one pymodbus AsyncModbusSerialClient per unique port
     - Spawns one asyncio task per port via _port_polling_loop()
     - Waits for all tasks (gather), handles cancellation on shutdown
   - `async def _port_polling_loop(self, port: str, client: AsyncModbusSerialClient, devices: list[ModbusDevice]) -> None`:
     - Per CONTEXT.md: round-robin by priority within port
     - Loop while not cancelled:
       a. now_ms = monotonic_ms()
       b. For each device sorted by priority:
          - if not device.should_poll: continue
          - try: raw = await asyncio.wait_for(device.poll(client), timeout=device.timeout_s)
          - if raw is not None: device.on_success(raw, now_ms)
          - except (asyncio.TimeoutError, ModbusIOException): device.on_failure(now_ms, fault_type="timeout")
          - except ModbusException as e: device.on_failure(now_ms, fault_type=f"exception_{e.exception_code}")
       c. await asyncio.sleep(0.050) -- 50ms minimum loop period per RESEARCH.md
   - `async def shutdown(self) -> None` -- cancels all tasks, closes clients
   - pymodbus client config per CONTEXT.md: framer=FramerType.RTU, baudrate from config, reconnect_delay=0 (we handle backoff ourselves)

2. Create __main__.py:
   - `def main() -> None`:

     b. Load device configs: pcs_config.yaml, btms_config.yaml, meter_config.yaml, dg_config.yaml, pv_config.yaml
     c. Attach to RTDB via ems_common.rtdb.attach_rtdb()
     d. Create ZMQ context, PUSH socket to SOCK_LOGGER

     f. Create CommOrchestrator with devices
     g. Signal handling: SIGTERM/SIGINT trigger orchestrator.shutdown()
     h. asyncio.run(orchestrator.run())
     i. Cleanup: detach RTDB, close ZMQ
   - Entry: `if __name__ == "__main__": main()`
