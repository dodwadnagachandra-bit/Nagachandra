**Register Map Design (CRITICAL):**

Registers are grouped contiguously by category to allow multi-register block reads (FC03 with count > 1). Writable setpoint/control registers remain at their PCS V1.24 canonical addresses (sparse).

Groups:
- AC side: 0x0001–0x000C (12 registers: V/I/power per phase + freq + PF + apparent + reactive)
- DC side: 0x0010–0x0013 (4 registers: V, I, power, efficiency placeholder)
- Thermal: 0x0020–0x0022 (3 registers: heatsink, ambient, internal)
- Status: 0x0030–0x0033 (4 registers: state, fault code, warning code, run hours)
- Energy: 0x0040–0x0043 (4 registers: kWh charge hi/lo, kWh discharge hi/lo)
- Control setpoints: 0x0291 (on/off), 0x0292 (fault reset), 0x500E (active power), 0x500F (reactive power), 0x5010 (PF setpoint)

**Signed register convention:** Two's complement for signed values (power, current). Register map YAML has `signed: true` flag. Conversion: if value < 0, store as `value + 65536` (uint16 two's complement).
</context>

"""PCS telemetry signal generation with sinusoidal drift and Gaussian noise."""
```

Class `PCSSignalGenerator`:
- `__init__(self, nominal_voltage: float = 230.0, nominal_frequency: float = 50.0, dc_voltage: float = 48.0, phase_count: int = 3) -> None`
  - Store all params
  - Store `start_time = time.monotonic()`

- `_elapsed(self) -> float`: returns monotonic elapsed seconds

- `ac_voltage(self, phase: int = 1) -> float`:
  - Only phase 1 for single-phase (phase_count == 1), phases 2/3 return 0.0
  - base = nominal_voltage
  - drift = 5.0 * sin(2*pi*elapsed/120.0 + phase * 2.094)  # 120deg phase offset
  - noise = gauss(0, 0.5)
  - Clamp to [nominal_voltage * 0.85, nominal_voltage * 1.15]

- `ac_frequency(self) -> float`:
  - base = nominal_frequency
  - drift = 0.2 * sin(2*pi*elapsed/180.0)
  - noise = gauss(0, 0.02)
  - Clamp to [nominal_frequency - 1.0, nominal_frequency + 1.0]

- `dc_voltage(self) -> float`:
  - base = self._dc_voltage
  - drift = 2.0 * sin(elapsed/90.0)
  - noise = gauss(0, 0.3)
  - Clamp to [self._dc_voltage * 0.8, self._dc_voltage * 1.2]

- `dc_bus_voltage(self) -> float`:
  - Stable 400V with small noise: 400.0 + gauss(0, 1.0)
  - Clamp [350, 450]

- `temperature(self, base: float = 30.0, load_factor: float = 0.0) -> float`:
  - temp = base + load_factor * 25.0 (0-25 deg rise at full load)
  - drift = 2.0 * sin(elapsed/300.0)
  - noise = gauss(0, 0.3)
  - Clamp [-20, 85]

All methods have return type annotations. Use `import math`, `import random`, `import time`.

**B. Create `tools/simulators/modbus_sim/state_machine.py`:**

"""PCS state machine: STANDBY → STARTING → RUNNING → STOPPING → FAULT"""
```

Enum `PCSState(enum.IntEnum)`:
- STANDBY = 0
- STARTING = 1
- RUNNING = 2
- STOPPING = 3
- FAULT = 4

Class `PCSStateMachine`:
- `__init__(self, startup_delay_s: float = 2.0, shutdown_delay_s: float = 1.5, ramp_rate_pct_per_s: float = 10.0, rated_power_kw: float = 50.0) -> None`
  - `self.state: PCSState = PCSState.STANDBY`
  - `self.power_setpoint_kw: float = 0.0`
  - `self.current_power_kw: float = 0.0`
  - `self.fault_code: int = 0`
  - `self.warning_code: int = 0`
  - `self._transition_start: float = 0.0`
  - `self._run_hours: float = 0.0`

- `command_start(self) -> None`:
  - Only from STANDBY → STARTING. Log transition. Record _transition_start = time.monotonic().

- `command_stop(self) -> None`:
  - Only from RUNNING → STOPPING. Log transition. Record _transition_start.

- `command_fault_reset(self) -> None`:
  - Only from FAULT → STANDBY. Clear fault_code and warning_code. Log.

- `set_power_setpoint(self, raw_value: int, scale: int = 10) -> None`:
  - Convert raw to kW: `raw_value / scale` (handle two's complement: if raw_value > 32767, subtract 65536)
  - Only store if state == RUNNING. Log.

- `tick(self, dt_s: float) -> None`:
  - If STARTING: check elapsed >= startup_delay_s → transition to RUNNING
  - If STOPPING: ramp current_power_kw toward 0, check elapsed >= shutdown_delay_s → STANDBY, reset current_power_kw=0
  - If RUNNING: ramp current_power_kw toward power_setpoint_kw at ramp_rate_pct_per_s. Accumulate _run_hours.
  - Ramp logic: max_delta = rated_power_kw * ramp_rate_pct_per_s / 100.0 * dt_s. Move toward setpoint by min(max_delta, abs(diff)).

- Properties:
  - `load_factor` -> float: abs(current_power_kw) / rated_power_kw, clamped [0, 1]
  - `run_hours` -> int: int(self._run_hours)

    - Log: "Modbus TCP server on port {tcp_port}"

  - Wrap in try/finally: cancel updater, stop PTY pair

- `async _telemetry_loop(self, interval_s: float = 1.0) -> None`:
  - Each tick:
    - Call state_machine.tick(interval_s)
    - Compute load_factor from state machine
    - Update ALL register values based on state:
      - AC voltage L1/L2/L3: signal_gen.ac_voltage(phase) — always live
      - AC frequency: signal_gen.ac_frequency() — always live
      - AC current L1/L2/L3: if RUNNING, current = power / voltage / phase_count. Else 0.
      - AC active power: state_machine.current_power_kw if RUNNING, else 0
      - AC reactive/apparent/PF: derive from active power
      - DC voltage: signal_gen.dc_voltage() — always live
      - DC current/power: derive from AC power with ~97% efficiency if RUNNING, else 0
      - DC bus voltage: signal_gen.dc_bus_voltage() — always live
      - Temperatures: signal_gen.temperature(base, load_factor)
      - Status: state_machine.state.value, fault_code, warning_code, run_hours
    - Scale all values and write to context using setValues
    - Handle signed registers: if negative, convert to two's complement uint16
    - Clamp all values to [0, 65535] after scaling
    - await asyncio.sleep(interval_s)

- `def stop(self) -> None`:
  - Cancel server and updater tasks
  - For clean shutdown from signal handler

- Build a helper method `_to_uint16(self, value: float, scale: int, signed: bool) -> int`:
  - raw = int(value * scale)
  - if signed and raw < 0: raw = raw + 65536 (two's complement)
  - return max(0, min(65535, raw))
