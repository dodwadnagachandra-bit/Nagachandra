<task type="auto">
  <name>Task 2: Create GitHub Actions CI/CD workflows (PR check + master merge)</name>
  <files>
    .github/workflows/pr-check.yml
    .github/workflows/master-merge.yml
  </files>
  <action>
    Create two GitHub Actions workflow files following Patterns 4 and the master-merge example from RESEARCH.md.

    **1. .github/workflows/pr-check.yml** (fast, <5 min target):

    Trigger: `pull_request` to `master` branch.
    Runner: `ubuntu-22.04` (pinned, not `ubuntu-latest` — see Pitfall 6 in RESEARCH.md).

    Steps (single job `build-and-test`):
    1. `actions/checkout@v4`
    2. Install system deps: `sudo apt-get update && sudo apt-get install -y cmake ninja-build clang-format`
    3. Configure CMake (native Debug): `cmake -B build -DCMAKE_BUILD_TYPE=Debug`
    4. Build C targets: `cmake --build build -- -j$(nproc)`
    5. Run C tests: `ctest --test-dir build --output-on-failure`
    6. Install uv: `astral-sh/setup-uv@v7` with `enable-cache: true` and `python-version: "3.12"`
    7. Install Python deps: `uv sync --locked --all-extras --dev`
    8. Run Python tests: `uv run pytest tests/ -v`
    9. Check C formatting: `find src -name "*.c" -o -name "*.h" | xargs clang-format --dry-run --Werror`
    10. Check Python lint + format: `uv run ruff check src/ && uv run ruff format --check src/`

    **2. .github/workflows/master-merge.yml** (full suite):

    Trigger: `push` to `master` branch.
    Runner: `ubuntu-22.04` (pinned).

    Steps (single job `full-suite`):
    1. `actions/checkout@v4`
    2. Install system deps (native + cross): `sudo apt-get update && sudo apt-get install -y cmake ninja-build clang-format gcc-aarch64-linux-gnu g++-aarch64-linux-gnu`
    3. Configure and build (native Debug): cmake -B build + cmake --build build
    4. Run C tests (native): `ctest --test-dir build --output-on-failure`
    5. Cross-compile for ARM64: cmake -B build-arm with toolchain file, Release
    6. Verify ARM64 binary architecture: `file` command on all executables, grep for "aarch64"
    7. Install uv: `astral-sh/setup-uv@v7` with `enable-cache: true` and `python-version: "3.12"`
    8. Install Python deps: `uv sync --locked --all-extras --dev`
    9. Run Python tests: `uv run pytest tests/ -v`
    10. Lint + format check: clang-format --dry-run --Werror + ruff check + ruff format --check
    11. Setup bun: `oven-sh/setup-bun@v2`
    12. Install HMI deps: `cd src/hmi_server/frontend && bun install`
    13. Build HMI: `cd src/hmi_server/frontend && bun run build`
    14. Test HMI: `cd src/hmi_server/frontend && bun test`

    **Important CI decisions:**
    - Always pin `ubuntu-22.04` (never `ubuntu-latest`)
    - Always use `--locked` with `uv sync` in CI (fails if lockfile is stale)
    - Use `astral-sh/setup-uv@v7` with `enable-cache: true` for fast Python dependency installs
    - Use `oven-sh/setup-bun@v2` for bun in CI
    - The `find src -name "*.c" -o -name "*.h"` pattern for clang-format handles the nested module structure
    - ruff must run BOTH `check` (lint) AND `format --check` (formatting) — see Pitfall 5 in RESEARCH.md
    - Python version in CI matches `requires-python = ">=3.12"` via setup-uv python-version parameter
  </action>
