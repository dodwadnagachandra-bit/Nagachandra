**CAN ID Stride Design (CRITICAL):**

The existing bms_config schema defines: `base_id + (cluster * 0x100 + rack)`. However, each rack has 10 message types (offsets 0x00-0x09). With rack indices only 1 apart, message offsets collide across racks.

**Solution:** Compute actual CAN ID as:
```
can_id = base_id + cluster * 0x1000 + rack * 0x10 + msg_offset
```

This gives:
- Each rack: 16 ID slots (10 used + 6 reserved)
- Each cluster: 4096 ID slots (up to 256 racks)
- Rack 0: base + 0x00..0x09
- Rack 1: base + 0x10..0x19
- Rack 2: base + 0x20..0x29
- Cluster 1 Rack 0: base + 0x1000..0x1009

For residential (1 cluster, 4 racks): IDs span base+0x00 to base+0x39 (no collisions).
For container (4 clusters, 16 racks): IDs span base+0x00 to base+0x30F9 (no collisions).

The DBC file defines 10 "template" messages at arbitrary base IDs. At runtime, the simulator encodes by message name and overrides the CAN ID per rack. This scales to any rack count without DBC changes.

**CAN ID convention:** All IDs are extended (29-bit) CAN 2.0B. In DBC format, extended IDs have bit 31 set. Use the base_id 0x98FF0003 for the first template message. Since 0x98FF0003 already exceeds 0x7FFFFFFF, bit 31 is inherently set. The actual 29-bit ID is `0x98FF0003 & 0x1FFFFFFF = 0x18FF0003`.

For the DBC file, define template messages at sequential offsets from the base. Use decimal values of `base_id + offset` (which already include the extended frame flag). The base 0x98FF0003 = 2566914051 decimal.

**10 message definitions (all from node BMU to EMS, 8 bytes each):**

1. **PackSummary (offset 0x00, ID 2566914051):** Fast cycle.
   - `pack_v`: bits 0|16, unsigned, scale 0.1, offset 0, range [0|1000], unit "V"
   - `pack_i`: bits 16|16, **signed** (@1-), scale 0.1, offset 0, range [-3000|3000], unit "A"
   - `pack_soc`: bits 32|8, unsigned, scale 0.5, offset 0, range [0|100], unit "%"
   - `pack_soh`: bits 40|8, unsigned, scale 0.5, offset 0, range [0|100], unit "%"
   - `fault_code`: bits 48|16, unsigned, scale 1, offset 0, range [0|65535], unit ""

2. **CellVoltage_01 (offset 0x01, ID 2566914052):** Fast cycle. Cells 1-4.
   - `cell_v_01` through `cell_v_04`: each 16-bit unsigned, scale 0.001, offset 0, range [0|5], unit "V"
   - Bit positions: 0|16, 16|16, 32|16, 48|16

3. **CellVoltage_02 (offset 0x02, ID 2566914053):** Fast cycle. Cells 5-8.
   Same layout as CellVoltage_01 but signals named `cell_v_05` through `cell_v_08`.

4. **CellVoltage_03 (offset 0x03, ID 2566914054):** Fast cycle. Cells 9-12.
   Signals `cell_v_09` through `cell_v_12`.

5. **CellVoltage_04 (offset 0x04, ID 2566914055):** Fast cycle. Cells 13-16.
   Signals `cell_v_13` through `cell_v_16`.

6. **CellVoltage_05 (offset 0x05, ID 2566914056):** Fast cycle. Cells 17-20.
   Signals `cell_v_17` through `cell_v_20`.

7. **CellVoltage_06 (offset 0x06, ID 2566914057):** Fast cycle. Cells 21-24.
   Signals `cell_v_21` through `cell_v_24`.

8. **CellVoltage_07 (offset 0x07, ID 2566914058):** Fast cycle. Cells 25-28.
   Signals `cell_v_25` through `cell_v_28`.

9. **CellTemperature (offset 0x08, ID 2566914059):** Slow cycle.
   - `cell_t_01` through `cell_t_08`: each 8-bit unsigned, scale 1, offset -40, range [-40|215], unit "degC"
   - Bit positions: 0|8, 8|8, 16|8, 24|8, 32|8, 40|8, 48|8, 56|8
   - The offset -40 means raw value 0 = -40 degC, raw 72 = 32 degC (typical operating temp)

10. **RackStatus (offset 0x09, ID 2566914060):** Slow cycle.
    - `online`: bits 0|8, unsigned, scale 1, offset 0, range [0|1], unit ""
    - `balancing_count`: bits 8|8, unsigned, scale 1, offset 0, range [0|255], unit ""
    - `min_cell_v`: bits 16|16, unsigned, scale 0.001, offset 0, range [0|5], unit "V"
    - `max_cell_v`: bits 32|16, unsigned, scale 0.001, offset 0, range [0|5], unit "V"
    - `avg_cell_v`: bits 48|16, unsigned, scale 0.001, offset 0, range [0|5], unit "V"

All signals use little-endian byte order (Intel format, `@1` in DBC notation).

**A. Create `tools/simulators/can_sim/signals.py`:**

```python
"""Signal data generation with sinusoidal drift and Gaussian noise."""
```

Class `SignalGenerator`:
- `__init__(self, rack_index: int, cluster_index: int = 0) -> None`
  - Store `rack_index`, `cluster_index`
  - Compute `rack_offset = (cluster_index * 16 + rack_index) * 0.02` for per-rack variation
  - Store `start_time = time.monotonic()`

- `_elapsed(self) -> float`: returns monotonic elapsed seconds

- `cell_voltage(self, cell_idx: int) -> float`:
  - base = 3.35 + self.rack_offset
  - drift = 0.15 * sin(2*pi*elapsed/60.0 + cell_idx * 0.1)
  - noise = gauss(0, 0.005)
  - Clamp to [2.5, 4.2]

- `cell_temperature(self, temp_idx: int) -> float`:
  - base = 32.0 + self.rack_offset * 50
  - drift = 5.0 * sin(2*pi*elapsed/120.0 + temp_idx * 0.2)
  - noise = gauss(0, 0.5)
  - Clamp to [-10, 60]

- `pack_voltage(self) -> float`:
  - Sum of 16 cell voltages (default module cell count) or compute as base 52.0 + 2.0*sin(elapsed/60)
  - Simpler: base 52.0 + 2.0 * sin(elapsed/60.0) + self.rack_offset * 10

- `pack_current(self) -> float`:
  - 50.0 * sin(2*pi*elapsed/60.0)

- `pack_soc(self) -> float`:
  - 600s cycle: first 300s ramp 20->80, second 300s ramp 80->20
  - Clamp to [0, 100]

- `pack_soh(self) -> float`:
  - Static 98.0

- `min_max_avg_cell_v(self, num_cells: int = 16) -> tuple[float, float, float]`:
  - Generate num_cells voltages, return (min, max, mean)

- `min_max_avg_cell_t(self, num_temps: int = 8) -> tuple[float, float, float]`:
  - Generate num_temps temperatures, return (min, max, mean)

All methods have return type annotations. Use `import math`, `import random`, `import time`.

Class `RackSimulator`:
- `__init__(self, bus: can.BusABC, db: cantools.Database, rack_index: int, cluster_index: int, base_can_id: int, fast_cycle_s: float, slow_cycle_s: float, num_cells: int = 16, num_temps: int = 8, verbose: bool = False) -> None`
  - Store all params
  - Create `SignalGenerator(rack_index, cluster_index)`
  - Compute `rack_base_id = base_can_id + cluster_index * 0x1000 + rack_index * 0x10`
  - Build message name list for the 10 DBC messages

- `_send_frame(self, msg_name: str, msg_offset: int, signals: dict[str, float | int]) -> None`:
  - `data = self.db.encode_message(msg_name, signals)`
  - `can_id = self.rack_base_id + msg_offset`
  - `msg = can.Message(arbitration_id=can_id, data=data, is_extended_id=True)`
  - `self.bus.send(msg)`
  - If verbose, log the frame

- `_send_fast_cycle(self) -> None`:
  - Send PackSummary (offset 0x00): pack_v, pack_i, pack_soc, pack_soh, fault_code=0
  - Send CellVoltage_01 through CellVoltage_07 (offsets 0x01-0x07): 4 cell voltages each
    - Only send the cell voltage messages needed for num_cells. For 16 cells, send CellVoltage_01 through CellVoltage_04 (cells 1-16). For 28 cells, send all 7. For cells beyond num_cells, send 0.0.

- `_send_slow_cycle(self) -> None`:
  - Send CellTemperature (offset 0x08): 8 temperature values (or num_temps, padded with 0)
  - Send RackStatus (offset 0x09): online=1, balancing_count=0, min/max/avg cell voltage

- `async run_fast(self) -> None`:
  - Drift-corrected periodic loop at fast_cycle_s
  - Each iteration calls `_send_fast_cycle()`
  - Use `loop.time()` for drift correction (see research pitfall #2)

- `async run_slow(self) -> None`:
  - Drift-corrected periodic loop at slow_cycle_s
  - Each iteration calls `_send_slow_cycle()`

- `async run(self) -> None`:
  - `await asyncio.gather(self.run_fast(), self.run_slow())`

Note: `bus.send()` is synchronous but fast (kernel buffers). No need for `run_in_executor` for vcan.
