    - Daily file path: data_dir/events/{year}/{month:02d}/events_{YYYYMMDD}.jsonl
    - File rotates when event date differs from current file date
    - fsync every 100 writes or on explicit flush (not every single write)
    - read_events(path) static method reads JSONL file, skipping lines that fail json.loads()

    - _rotate(date_str: str) -> None: close current file, open new one in events/{year}/{month:02d}/ directory
    - _sync() -> None: flush + os.fsync

    - Static read_events(path: Path) -> list[dict]: read file line by line, json.loads each, skip lines that raise JSONDecodeError (LOG-07 crash recovery)
