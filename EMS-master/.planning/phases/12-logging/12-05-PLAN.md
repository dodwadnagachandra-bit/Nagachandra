  <behavior>
    - get_disk_usage_pct(path) returns disk usage percentage via os.statvfs()
    - RetentionManager.run_cleanup() executes three-tier FIFO when disk > threshold
    - Tier 1: delete expired Parquet (oldest first)
    - Tier 2: delete expired JSONL (oldest first) -- only if still above threshold after tier 1
    - Tier 3: delete within-retention data oldest-first (Parquet before JSONL) -- survival mode
    - run_periodic() async: runs cleanup every cleanup_interval_s seconds
    - Cleanup logs every deletion with file path and size
    - Empty directories are removed after file deletion
  </behavior>
  <action>
    Add to cleanup.py:

    1. get_disk_usage_pct(path: str | Path) -> float:
       os.statvfs(), compute (total - free) / total * 100.

    2. _delete_files(files: list[Path], threshold_pct: float, data_dir: Path) -> int:
       Delete files one at a time until disk usage drops below threshold or list exhausted.
       Remove empty parent directories after deletion. Return count deleted. Log each deletion.

    3. RetentionManager class:
       - __init__(config: LoggerConfig)
       - run_cleanup() -> dict[str, int]: Execute three-tier FIFO.
         Tier 1: find_expired_parquet -> _delete_files
         Check disk: if still above threshold ->
         Tier 2: find_expired_jsonl -> _delete_files
         Check disk: if still above threshold ->
         Tier 3: find ALL parquet sorted oldest-first -> _delete_files; if still above -> find ALL jsonl oldest-first -> _delete_files

       - startup_recovery() -> None: cleanup_stale_tmp(data_dir)
       - run_periodic() async: loop calling run_cleanup every cleanup_interval_s, log results
