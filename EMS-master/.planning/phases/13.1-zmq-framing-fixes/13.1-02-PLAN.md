<task type="auto">
  <name>Task 2: Add dedicated ZMQ framing verification tests</name>
  <files>tests/test_zmq_framing.py</files>
  <action>
Create a new test file `tests/test_zmq_framing.py` that verifies the corrected C-to-Python framing works end-to-end. These tests use ZMQ in-process to validate framing contracts without requiring the C binary.

The file should contain:

1. **Test class `TestPubFraming`** -- verifies 2-frame PUB convention:

   `test_python_pub_sends_two_frames`: Create PUB+SUB pair on tcp://127.0.0.1 with a random port. Use TelemetryPublisher.publish_once() or manually send 2 frames `[topic|body]`. SUB receives and asserts `len(parts) == 2`. Unpack frame[1] as msgpack and verify it has expected keys (ts, seq, src, topic, payload).

   `test_sub_rejects_three_frame_messages`: Create a PUB that deliberately sends 3 frames `[topic|junk|body]`. Create TelemetryWriter's _collect_window logic (or replicate its `len(parts) != 2: continue` check). Verify the 3-frame message is dropped. Then send a valid 2-frame message and verify it IS accepted.

2. **Test class `TestPushPullFraming`** -- verifies single-frame PUSH convention:

   `test_push_single_frame_decoded_by_event_consumer`: Create PUSH+PULL pair on tcp://127.0.0.1. Send a single msgpack frame (matching what the fixed C code sends): `encode_event(ts, src, severity, event_type, message, data)` from ems_common.ipc. On PULL side, do `data = sock.recv()` then `decode_event(data)`. Assert the decoded dict has correct fields.

   `test_push_with_length_prefix_fails_decode`: Create PUSH+PULL pair. Send the OLD framing: `[4-byte BE len | SNDMORE] [msgpack body]`. On PULL side, `data = sock.recv()` gets the 4-byte prefix (not msgpack). Assert that `decode_event(data)` raises an exception (proving the old framing was broken).

3. **Test class `TestSharedPubSocket`** -- verifies DEFECT-1 fix:

   `test_health_and_publisher_share_socket`: Create a PUB socket, bind it. Create TelemetryPublisher-like object and HealthMonitor both using the same socket. Create a SUB that subscribes to both "pcs" and "system.health" topics. Verify messages from both arrive on the same SUB -- proving shared socket works.

   `test_double_bind_same_endpoint_fails`: Attempt to bind two PUB sockets to the same tcp endpoint. Assert the second bind raises zmq.ZMQError. This documents why the old approach was broken.

Use `pytest` conventions. Type annotations on all functions. Use `zmq.Context()` (sync) for simplicity since these are framing tests, not async tests. Use unique tcp ports per test (15570-15579 range) to avoid conflicts with other test classes.

Import from `ems_common.ipc` for encode_event, decode_event, SEVERITY_WARNING, and message key constants.
