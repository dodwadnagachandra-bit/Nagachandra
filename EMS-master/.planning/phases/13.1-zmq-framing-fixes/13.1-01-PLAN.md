  <action>
Modify HealthMonitor in health.py to accept an existing PUB socket instead of creating and binding its own:

1. Change `__init__` signature: replace `zmq_ctx` and `endpoint` parameters with a single `pub_socket: zmq.Socket | zmq.asyncio.Socket` parameter. 2. Remove the `endpoint` property (no longer meaningful -- HealthMonitor does not own the socket).

3. In `close()`: remove `self._pub.close()` entirely -- HealthMonitor does not own the socket, so it must NOT close it. The TelemetryPublisher owns the socket lifecycle. Just make close() a no-op or log a message.

4. In __main__.py `run()` function: change HealthMonitor construction from:
   ```python
   health = HealthMonitor(rtdb, ctx, stale_threshold_ms=args.stale_threshold)
   ```
   to:
   ```python
   health = HealthMonitor(rtdb, publisher.pub_socket, stale_threshold_ms=args.stale_threshold)
   ```

5. In publisher.py: add a read-only property `pub_socket` that returns `self._pub` so __main__.py can pass it to HealthMonitor:
   ```python
   @property

       return self._pub
   ```

6. In __main__.py cleanup: remove `health.close()` since HealthMonitor no longer owns a socket. Keep `publisher.close()` which closes the shared PUB socket.

Keep all existing HealthMonitor logic (check_once, monitor_loop, _publish_stale_warning) unchanged -- they all use self._pub which now points to the shared socket.

  <action>
Both files have identical framing patterns. Apply the same fix to both:

**safety_event.c -- safety_event_publish() function:**

1. Remove the length prefix variable: delete `uint32_t len_be = htonl((uint32_t)msg_len);`

2. Remove `#include <arpa/inet.h>` (no longer needed -- htonl was only used for length prefix).

3. Fix PUB send (lines 212-228): Change from 3-frame `[topic|SNDMORE][len_be|SNDMORE][body]` to 2-frame `[topic|SNDMORE][body]`:
   ```c
   if (ctx->pub_sock)
   {
       const char *topic = EMS_TOPIC_GPIO;

       /* Topic frame (SNDMORE) */
       if (zmq_send(ctx->pub_sock, topic, strlen(topic),
                    ZMQ_DONTWAIT | ZMQ_SNDMORE) >= 0)
       {
           /* Body frame (no SNDMORE) */
           zmq_send(ctx->pub_sock, buf, msg_len, ZMQ_DONTWAIT);
       }
       /* EAGAIN silently dropped -- safety outputs are priority */
   }
   ```

4. Fix PUSH send (lines 236-242): Change from 2-frame `[len_be|SNDMORE][body]` to single-frame `[body]`:
   ```c
   if (ctx->push_sock)
   {
       zmq_send(ctx->push_sock, buf, msg_len, ZMQ_DONTWAIT);
       /* EAGAIN silently dropped */
   }
   ```

5. Update the file-level Doxygen comment at the top to reflect the new framing contract:
   ```
    * Framing contract (matching Python convention):
    *   PUB:  [topic frame | SNDMORE] [msgpack body]
    *   PUSH: [msgpack body]  (single frame)
   ```
