**PcsDevice write methods (pcs_device.py):**

Add `_last_cmd_seq: int = 0` instance attribute in __init__.

Add `write_setpoint(self, client: AsyncModbusSerialClient) -> None`:
- Read system section via `_seqlock_read_section(self._rtdb.system)`
- Get `active_setpoint_kw` from the copy
- Convert to raw int16: `raw = int(round(setpoint_kw * 10))`. PCS V1.24 register 0x500E uses scale factor 10, signed 16-bit (two's complement for negative: `if raw < 0: raw = raw + 65536`). Clamp 0-65535.
- Call `await client.write_register(0x500E, raw, slave=self._slave_id)` (pymodbus FC06)
- If write fails (ModbusIOException), log warning but do not raise — stale setpoint is safe.

Add `process_command(self, client: AsyncModbusSerialClient) -> None`:
- Read system section via seqlock
- Get `pcs_command` and `pcs_command_seq` from the copy
- If `(new_seq - self._last_cmd_seq) & 0xFFFFFFFF == 0`: return (no new command)
- Update `self._last_cmd_seq = new_seq`
- If cmd == 1 (ON): `await client.write_register(0x0291, 1, slave=self._slave_id)`
- If cmd == 2 (OFF): `await client.write_register(0x0291, 0, slave=self._slave_id)`
- If cmd == 3 (FAULT_RESET): `await client.write_register(0x5064, 1, slave=self._slave_id)`
- Log each command execution at INFO level.

Note: The CommOrchestrator poll loop needs to call these methods after each poll cycle. Add `write_setpoint` and `process_command` calls in the orchestrator's poll loop for PCS devices. Check how the orchestrator currently calls `poll()` and add the write calls after poll completes.
