**1Hz loop (`async run(self)`):**
Follow the timing-corrected pattern from data_manager publisher.py:
```python
interval_s = self._config["state_machine"]["loop_interval_ms"] / 1000.0
while not self._stop_event.is_set():
    tick_start = time.monotonic()
    self._poll_commands()      # check REP socket (non-blocking)
    self._tick(tick_start)     # read RTDB, call SM, write RTDB, publish
    elapsed = time.monotonic() - tick_start
    await asyncio.sleep(max(0.0, interval_s - elapsed))
```

**_poll_commands():**
Use `zmq.NOBLOCK` recv on REP socket. On receive:
- Decode with `decode_command_request(raw)` -> (action, params)
- Dispatch to state machine request methods based on action string:
  - "mode_change" -> `_sm.request_mode_change(params["target_state"])`
  - "manual_setpoint" -> `_sm.request_manual_setpoint(params["power_kw"])`
  - "fault_reset" -> `_sm.request_fault_reset()`
  - "maintenance_enter" -> `_sm.request_maintenance_enter()`
  - "maintenance_exit" -> `_sm.request_maintenance_exit()`
  - "source_priority" -> store mode but defer actual logic to Phase 16; return ok
- Build response with `encode_command_response(status, result_or_error)`
- ALWAYS send reply (wrap entire block in try/except that sends error on any exception)

**_tick(now_s):**
1. Read RTDB sections via `_seqlock_read_section()`:
   - `pcs_copy = _seqlock_read_section(self._rtdb.pcs)` -> get state, fault_code
   - `gpio_copy = _seqlock_read_section(self._rtdb.gpio)` -> check safety outputs for emergency
   - `system_copy = _seqlock_read_section(self._rtdb.system)` -> get current control_state (for MAINTENANCE persistence on first tick)
2. Determine safety_emergency: check gpio_copy for emergency output asserted (check how safety_manager sets this — look at the GPIO section structure)
3. Call `result = self._sm.tick(now_s, pcs_copy.state, pcs_copy.fault_code, safety_emergency, system_copy.control_state)`
4. Write RTDB system section via seqlock:
   ```python
   sys = self._rtdb.system
   sys.lock.sequence += 1  # begin (odd)
   sys.control_state = result.state
   sys.active_setpoint_kw = result.setpoint_kw
   if result.pcs_command_changed:
       self._pcs_command_seq += 1
       sys.pcs_command = result.pcs_command
       sys.pcs_command_seq = self._pcs_command_seq
   sys.last_update_ms = _now_ms()
   sys.lock.sequence += 1  # end (even)
   ```
5. If `result.state_changed`: publish state_change event via PUSH to logger
6. Publish telemetry on PUB socket: `encode_telemetry(TOPIC_CONTROL_STATE, ts, "control_manager", {"state": result.state, "setpoint_kw": result.setpoint_kw, ...})`

**_seqlock_read_section():** Copy the pattern from data_manager publisher.py (retry loop, check odd sequence, memmove, compare sequences).

```python
import asyncio
import argparse
import logging
import signal
from pathlib import Path

from ems_control_manager.config import load_control_config
from ems_control_manager.loop import ControlLoop

logger = logging.getLogger("ems_control_manager")

async def main() -> None:
    parser = argparse.ArgumentParser(description="EMS Control Manager")
    parser.add_argument("--config", type=Path,
                        default=Path("config/control_config.yaml"),
                        help="Path to control_config.yaml")
    args = parser.parse_args()

    logging.basicConfig(level=logging.INFO,
                        format="%(asctime)s %(name)s %(levelname)s %(message)s")

    config = load_control_config(args.config)
    loop_obj = ControlLoop(config)

    asyncio_loop = asyncio.get_running_loop()
    stop_event = loop_obj.stop_event  # expose from ControlLoop

    def _signal_handler() -> None:
        logger.info("Shutdown signal received")
        stop_event.set()

    for sig in (signal.SIGTERM, signal.SIGINT):
        asyncio_loop.add_signal_handler(sig, _signal_handler)

    try:
        await loop_obj.run()
    finally:
        loop_obj.cleanup()
        logger.info("Control manager stopped")

if __name__ == "__main__":
    asyncio.run(main())
```
