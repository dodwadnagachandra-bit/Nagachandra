  1. Update `src/data_manager/python/pyproject.toml` to add dependencies: `pyzmq>=26.0`, `msgpack>=1.0`.

  2. Create `src/data_manager/python/src/ems_data_manager/publisher.py`:
     - Class `TelemetryPublisher`:
       - Constructor takes `rtdb: EmsRtdb`, `zmq_ctx: zmq.asyncio.Context`.
       - Binds ZMQ PUB on SOCK_TELEMETRY.
       - `async publish_loop() -> None`: Every 1 second (asyncio.sleep(1.0)):
         - Read each RTDB section using seqlock pattern. For each section: read lock.sequence, if odd (write in progress) retry. Copy section data via ctypes.memmove into a local buffer. Verify sequence unchanged. Extract fields into dict.
         - For BMS: iterate cluster_count * racks_per_cluster, publish each rack on topic "bms.rack.{c}.{r}".
         - For PCS, GPIO, meter, BTMS, system: publish on respective TOPIC_* constants.
         - Use `encode_telemetry()` from ems_common.ipc with incrementing sequence number.
         - Use `time.monotonic_ns() // 1_000_000` for timestamp_ms.

  3. Create `src/data_manager/python/src/ems_data_manager/health.py`:
     - Class `HealthMonitor`:
       - Constructor takes `rtdb: EmsRtdb`, `zmq_ctx: zmq.asyncio.Context`, `stale_threshold_ms: int = 5000`.
       - Connects ZMQ PUB on SOCK_TELEMETRY (same socket as publisher -- or use separate socket; simplest is to share the pub_sock via parameter).
       - `async monitor_loop() -> None`: Every 1 second, check each section's `last_update_ms` against current CLOCK_MONOTONIC. If `last_update_ms > 0` and `(now_ms - last_update_ms) > stale_threshold_ms`, publish stale warning event. Per locked decision: zero last_update_ms means "no data received yet" -- do NOT warn for zero.
       - Publish stale warnings on telemetry socket with topic "system.health" or push to logger.

  4. Add tests to `tests/test_data_manager.py`:

     - Use zmq.asyncio SUB socket in test to receive published messages.
     - Health test: set last_update_ms to old value, run one monitor cycle, verify stale warning published.
     - Health test: set last_update_ms to 0, verify no warning (no data yet).

  5. Run `uv sync --all-packages` after updating pyproject.toml.

       - `async snapshot_loop() -> None`: Every interval_s seconds, dump entire RTDB to disk.
       - `dump_snapshot(reason: str = "periodic") -> Path`: Copy full ctypes buffer (ctypes.memmove to bytes object of sizeof(ems_rtdb_t)), write to `{snapshot_dir}/rtdb_{timestamp}.bin.tmp`, then `os.rename` to final name (atomic write per research pitfall guidance).
