## Overview

M4 builds the cloud_manager (MQTT/TLS telemetry forwarding with paho-mqtt, offline disk buffering with JSONL FIFO replay, remote command dispatch) and ota_manager (HTTP firmware download, Ed25519 signature verification, A/B partition management with boot flag, automatic rollback on health check failure). These modules connect the EMS to the cloud at L5.

## Key Accomplishments

1. **Cloud Manager** — paho-mqtt client with mTLS, threaded network loop bridged to asyncio via threading.Queue, telemetry downsampling (1Hz→10-60s per profile), consolidated JSON publish to `{prefix}/telemetry`, event forwarding with QoS 1, remote command dispatch (7 commands including OTA trigger), heartbeat publishing, ZMQ connection status
2. **Offline Buffer** — JSONL hourly files in `data/cloud_buffer/`, dual retention limits (max_hours + max_mb), FIFO replay at 10 msg/s throttle with live data priority, crash-safe append (truncated line skip), automatic activation on MQTT disconnect
3. **OTA Manager** — HTTP download with Range resume and streaming SHA-256, Ed25519 signature verification via PyNaCl, mock partition backend (A/B with boot flag JSON), 6-state update pipeline (IDLE→DOWNLOADING→VERIFYING→APPLYING→REBOOTING→SUCCESS/ROLLED_BACK), automatic rollback on health check failure, version tracking via ZMQ REQ/REP
4. **Integration** — Mosquitto subprocess test fixture, E2E remote command flow (MQTT→ZMQ→control→RTDB), offline transition test (kill broker→buffer→restart→replay), OTA cycle with mock partitions, crash recovery for both modules

## Key Decisions Made

- paho-mqtt threaded loop with threading.Queue bridge to asyncio (not asyncio MQTT)
- Latest-value downsampling, single consolidated JSON message per interval
- QoS 0 for telemetry, QoS 1 for events
- JSONL offline buffer reusing logger's crash-safe append pattern
- FIFO replay throttled at 10 msg/s with live data priority
- Tar + Ed25519-signed manifest for OTA packages
- Boot flag JSON for A/B partition management
- HTTP download with MQTT notification (not direct MQTT binary transfer)
- Mock partition backend for testing, real partitions deferred to M5 Yocto
