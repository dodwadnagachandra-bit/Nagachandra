# Requirements: ReVx EMS

**Defined:** 2026-03-16
**Core Value:** Reliable, safe control of battery energy storage — safety manager protects equipment and people, control loop maintains correct power dispatch, system never loses telemetry data.

## v6.0 Requirements

Requirements for M5 — Diagnostics & Yocto. Each maps to roadmap phases.

### Diagnostics (diagnostics)

- [x] **DIAG-01**: SOH trending tracks battery State of Health per rack over time using cycle count, capacity fade, and internal resistance estimates from BMS telemetry
- [x] **DIAG-02**: PCS efficiency calculates AC/DC conversion efficiency from power measurements, tracks degradation over time, publishes on ZMQ telemetry
- [x] **DIAG-03**: Thermal analysis monitors BTMS performance — cooling effectiveness, ambient vs cell temperature delta trending, fan duty cycle tracking
- [x] **DIAG-04**: Communication health scoring rates each device (BMS racks, PCS, BTMS, Meter, DG, PV) on response rate, timeout frequency, and CRC error rate from comm_manager events
- [x] **DIAG-05**: Diagnostic report generation creates periodic summaries (daily/weekly) queryable via ZMQ REQ/REP for HMI diagnostics screen and cloud forwarding
- [x] **DIAG-06**: Predictive alerts detect degradation trends (SOH decline rate, efficiency drop, rising temperatures) and publish warning events before alarm thresholds are reached

### Production Hardening

- [x] **PROD-01**: Yocto recipe creation for all 12 Python packages and 5 C executables, with pinned dependency versions matching Ubuntu 24.04 development
- [x] **PROD-02**: Read-only rootfs configuration with tmpfs overlays for /tmp, /var/run, and /run/ems — data partition on SSD remains read-write
- [x] **PROD-03**: Real A/B partition integration replaces mock partition backend with actual rootfs partition swap via U-Boot environment variables
- [x] **PROD-04**: mTLS certificate provisioning workflow — device certificate generation, CA signing, secure key storage, certificate rotation plan
- [x] **PROD-05**: HMI cloud/OTA status integration — subscribe to SOCK_CLOUD_PUB and SOCK_OTA_PUB in WebSocket bridge, add status indicators to frontend
- [x] **PROD-06**: Production systemd hardening — ProtectSystem=strict, PrivateTmp=yes, NoNewPrivileges=yes, MemoryMax per service, watchdog integration
- [x] **PROD-07**: ECU-1170-552A hardware validation — boot test, driver verification (CAN, RS485, GPIO, HDMI), performance benchmarks on ARM64
