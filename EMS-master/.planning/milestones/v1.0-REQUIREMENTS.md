# Archived Requirements: v1.0 (M0 — Simulators & Platform)

**Defined:** 2026-02-26
**Completed:** 2026-03-13
**Core Value:** Reliable, safe control of battery energy storage — safety manager protects equipment and people, control loop maintains correct power dispatch, system never loses telemetry data.

## M0 Requirements (13 total)

### Simulators

- [x] **SIM-01**: CAN bus simulator generates realistic BMU→EMS Layer 2 traffic on vcan at configurable rates (300ms/2000ms cycles)
- [x] **SIM-02**: CAN simulator replays all L2 message IDs (0x98FF0003–0x98FF0903) with DBC-accurate signal encoding
- [x] **SIM-03**: Modbus RTU slave simulator responds to FC03/FC06 with PCS V1.24 telemetry on USB-RS485
- [x] **SIM-04**: Modbus simulator accepts setpoints on 0x500E (power) and 0x0291 (on/off) and reflects state changes
- [x] **SIM-05**: GPIO test harness simulates E-Stop (DI-6+7), Fire (DI-3+4), Flood (DI-1), ACDB (DI-0) signals
- [x] **SIM-06**: Simulators are configurable via YAML (fault injection, timing, multi-rack scaling)

### Platform

- [~] **PLAT-01**: Ubuntu 24.04 LTS boots on ECU-1170-552A with SocketCAN, GPIO (libgpiod), and RS485 drivers verified *(partial — CI cross-compile works, ECU hardware verification pending)*
- [x] **PLAT-02**: CI/CD pipeline builds C (CMake) and Python (uv) targets, runs unit tests (ctest + pytest)
- [x] **PLAT-03**: Monorepo scaffold with src/{module}/, config/, tests/, docs/ structure
- [x] **PLAT-04**: RTDB C header defines hierarchical struct (cluster→rack→module→cell) sized from config
- [x] **PLAT-05**: IPC message contracts defined (ZeroMQ topic schema, MessagePack payload formats)
- [x] **PLAT-06**: JSON Schema validation for all 14 YAML config files
- [x] **PLAT-07**: Cross-compilation toolchain configured for ARM64 (A53) target
