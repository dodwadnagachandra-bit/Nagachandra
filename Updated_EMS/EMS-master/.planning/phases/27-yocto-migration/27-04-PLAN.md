    **tools/gen-device-cert.sh:**
    Create the certificate generation script per CONTEXT.md and RESEARCH.md:

    Usage: `./tools/gen-device-cert.sh <site_id> <serial_number> <ca_key> <ca_cert> <out_dir>`

    Script logic:
    1. Validate all 5 arguments present, exit 1 with usage message if missing
    2. Set CN="${SITE_ID}-${SERIAL}" (e.g., "site001-ECU1170-0042")
    3. Generate RSA 4096-bit device private key: `openssl genrsa -out "${OUT}/device.key" 4096`
    4. Set permissions immediately: `chmod 600 "${OUT}/device.key"`
    5. Generate CSR with subject /CN=${CN}/O=ReVx-Energy/OU=EMS: `openssl req -new -key ... -subj ... -out device.csr`
    6. CA signs CSR with 365-day validity, SHA-256: `openssl x509 -req -in device.csr -CA ... -CAkey ... -CAcreateserial -days 365 -sha256 -out device.crt`
    7. Copy CA cert to output: `cp "${CA_CERT}" "${OUT}/ca.crt"`
    8. Remove CSR: `rm "${OUT}/device.csr"`
    9. Print summary: "Certificates generated for ${CN} in ${OUT}/"
    10. Set -euo pipefail at top of script
    11. Make executable (chmod +x)

    Also create a helper: `tools/gen-ca.sh` (optional but useful):
    - Generates a self-signed CA cert + key for development/testing
    - Usage: `./tools/gen-ca.sh <out_dir>`
    - `openssl req -x509 -newkey rsa:4096 -keyout ca.key -out ca.crt -sha256 -days 3650 -nodes -subj "/CN=ReVx-EMS-CA/O=ReVx-Energy"`
