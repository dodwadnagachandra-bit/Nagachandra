    **boot.cmd (U-Boot script source):**
    Per the RESEARCH.md pattern, create the bootscript that:
    1. Reads `ems_active_slot` env var (defaults to "a" if not set)
    2. Maps slot to device: a -> mmcblk0p2, b -> mmcblk0p3
    3. Reads `ems_boot_count` (defaults to 0)
    4. If ems_boot_count > 2: revert to previous slot, reset boot_count to 0, saveenv
    5. Increment ems_boot_count, saveenv
    6. Set bootargs: console=ttyS2,115200n8 root=/dev/${rootdev} ro rootfstype=ext4 rootwait systemd.unified_cgroup_hierarchy=1
    7. Load kernel Image from mmc 0:1 (boot partition)
    8. Load DTB (k3-am654-base-board.dtb) from mmc 0:1
    9. booti ${loadaddr} - ${fdtaddr}
