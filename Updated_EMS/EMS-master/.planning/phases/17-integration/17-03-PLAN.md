Atomic config modification pattern:
```python
def modify_config_atomic(path: Path, updates: dict) -> None:
    """Modify YAML atomically: read, update nested keys, write to .tmp, rename."""
    with open(path) as f:
        cfg = yaml.safe_load(f)
    for key_path, value in updates.items():
        keys = key_path.split(".")
        obj = cfg
        for k in keys[:-1]:
            obj = obj[k]
        obj[keys[-1]] = value
    tmp = path.with_suffix(".tmp")
    with open(tmp, "w") as f:
        yaml.dump(cfg, f)
    os.rename(tmp, path)  # atomic on Linux same-filesystem
```

Config reload chain: file modify -> inotify IN_MOVED_TO -> config_manager validates -> ZMQ PUB config_reload event -> module re-reads from disk -> applies

Timing: 500ms debounce + validation + ZMQ delivery + 1 tick = ~1.5s expected. Test allows 2s.
