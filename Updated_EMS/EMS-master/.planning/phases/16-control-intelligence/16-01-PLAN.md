  <behavior>
    Source Priority (CTRL-04):
    - DAY mode: iterates day_order [solar, grid, bess, dg], returns first available source
    - NIGHT mode: iterates night_order [grid, bess, dg], returns first available source
    - MANUAL mode: returns "manual" (bypasses priority entirely)
    - Solar available when gpio_di[0]==1 is NOT the check — solar availability uses a solar_available bool param (PV power > threshold check done by caller)
    - Grid available when gpio_di[0]==1 (ACDB feedback DI-0)
    - BESS available when total_soc > discharge_cutoff_pct AND current_state != STATE_FAULT
    - DG: always False in M2 (no dg_available field in RTDB)
    - No source available: active_source="none", soc_cutoff_hit=False (caller forces IDLE)

    SOC Limits (CTRL-05):
    - Charging + SOC >= charge_cutoff_pct => soc_cutoff_hit=True
    - Discharging + SOC <= discharge_cutoff_pct => soc_cutoff_hit=True
    - Other states or SOC within range => soc_cutoff_hit=False

    Temperature Derating (CTRL-06):
    - BMS high: signal=bms_max_cell_t, start=40, cutoff=50, linear 100%->0%
    - PCS high: signal=pcs_temp_c, start=65, cutoff=80, linear 100%->0%
    - BMS low: signal=bms_min_cell_t, start=5, cutoff=0, inverted linear 100%->0%
    - Most restrictive (min) wins
    - active_derating_pct returned in result (0.0-100.0 where 100=full power)
    - effective_max_power_kw = max_power_kw * active_derating_pct / 100

    Power Ramping (CTRL-08):
    - Setpoint change limited to ramp_rate_kw_s * delta_t_s per tick
    - Uses actual elapsed time (time.monotonic() delta), not configured interval
    - Ramp applies to both charge and discharge directions
    - If desired change <= max_step, snap to desired (no overshoot)

    Interlocks (CTRL-09):
    - safety_emergency=True => interlock_blocked=True
    - PCS state != PCS_STATE_RUNNING => interlock_blocked=True (only relevant for STANDBY->dispatch)
    - Both clear => interlock_blocked=False

    Alarm Protection (for Plan 16-02 integration):
    - alarm_severity="protection" => protection_active=True
    - alarm_severity="action" => desired_setpoint_kw reduced to 50% of raw_setpoint
    - alarm_severity="warning" or None => no effect
    - protection_active flag used by caller to enter FAULT state

    Config Update:
    - update_config(new_config) atomically replaces all internal config references
  </behavior>
