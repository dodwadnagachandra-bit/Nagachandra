    - ReportBuilder(analyzers_dict, config) holds references to all 4 analyzers and config
    - build_current() -> dict: aggregates get_current() from all analyzers into single response
    - build_report(period: str) -> dict: "daily" or "weekly", queries logger for historical data via provided query_fn callback, returns trend summaries
    - build_predictions(soh_analyzers: list[SohAnalyzer]) -> dict: runs statistics.linear_regression on SOH history, projects days to threshold
    - Predictions return empty list if < min_history_days data points
    - Linear regression: slope < 0 means degradation, project (threshold - current) / slope = days_to_threshold
    - build_predictions returns {"predictions": [{"metric": "soh", "rack_id": int, "current_value": float, "trend_rate_per_day": float, "days_to_threshold": float | None, "severity": str}]}

       - Class ReportBuilder with __init__(config: DiagnosticsConfig)
       - build_current(soh_analyzers: list[SohAnalyzer], pcs: PcsAnalyzer, thermal: ThermalAnalyzer, comm: CommAnalyzer) -> dict:
         * Return {"soh": [a.get_current() for a in soh_analyzers], "pcs_efficiency": pcs.get_current(), "thermal": thermal.get_current(), "comm": comm.get_current()}
       - build_report(period: str, query_fn: Callable) -> dict:
         * period = "daily" or "weekly"
         * window_hours = 24 if daily else 168
         * Call query_fn with range_stats params for SOH, PCS efficiency trends
         * Call query_fn with event_log params for comm fault summary
         * Return {"period": period, "generated_at": timestamp_ms, "soh_trend": [...], "efficiency_trend": [...], "comm_summary": [...], "alerts": [...]}

         * For each analyzer with >= min_history_days history points:
           Use statistics.linear_regression(x_days, y_soh)
           If slope < 0: days_to_threshold = (soh_critical_pct - current_soh) / slope
           severity = "warning" if days < 90, "critical" if days < 30
         * Return {"predictions": [...]}
       - Helper: _classify_severity(days_to_threshold: float | None) -> str

    1. Create src/diagnostics/src/ems_diagnostics/loop.py:
       - Class DiagnosticsLoop with __init__(config: DiagnosticsConfig, zmq_ctx: zmq.Context | None = None)
       - Setup in __init__:
         * Create zmq.Context if not provided
         * Create SUB socket connected to SOCK_TELEMETRY, subscribed to TOPIC_BMS_RACK, TOPIC_PCS, TOPIC_BTMS
         * Create REQ socket connected to SOCK_LOGGER_QUERY
         * Create PUB socket bound to SOCK_DIAGNOSTICS_PUB
         * Create REP socket bound to SOCK_DIAGNOSTICS_CMD
         * Create PUSH socket connected to SOCK_LOGGER
         * Initialize analyzers: SohAnalyzer per rack (rack count from config or default 1), PcsAnalyzer, ThermalAnalyzer, CommAnalyzer
         * Initialize ReportBuilder(config)
         * Create asyncio.Event for stop signal
       - async run() -> None: await asyncio.gather of 5 tasks
       - async _telemetry_collector() -> None:
         * Non-blocking drain of SUB socket at 100Hz poll (per cloud_manager pattern)
         * Route by topic: bms.rack.{N} -> SohAnalyzer[N].update(), pcs -> PcsAnalyzer.update(), btms -> ThermalAnalyzer.update()
         * Decode with decode_telemetry, extract payload fields
       - async _hourly_trend_updater() -> None:
         * Every config.intervals.trend_update_s seconds:
         * Query logger for range_stats (SOH averages) and event_log (comm faults)
         * Run queries in asyncio executor (not blocking event loop — Pitfall 3)
         * Update CommAnalyzer with event_log results
         * Add history points to SohAnalyzers
       - async _diagnostics_publisher() -> None:
         * Every config.intervals.publish_s seconds:
         * Build current metrics via ReportBuilder.build_current()
         * Publish on SOCK_DIAGNOSTICS_PUB with topic TOPIC_DIAGNOSTICS
         * Encode with msgpack
       - async _report_server() -> None:
         * Non-blocking drain of REP socket at 100Hz poll (per alarm_manager pattern)
         * Dispatch: get_current -> build_current(), get_report -> build_report(), get_predictions -> build_predictions()
         * ALWAYS send reply (even on error — Pitfall 6)
         * Wrap in try/except with encode_command_response("error", error_msg=str(exc))
       - async _predictive_alert_checker() -> None:
         * Every config.intervals.publish_s seconds (same as publisher):
         * Call build_predictions() for each SohAnalyzer
         * If any prediction has days_to_threshold < 90 (configurable):
           Encode event via encode_event(source="diagnostics", severity=WARNING, event_type="predictive_alert", ...)
           Send via PUSH to SOCK_LOGGER
       - stop() -> None: set _stop_event, close all sockets

       - For all tests: use short timeouts (0.5s), mock logger REQ responses
