    **__init__:**
    1. `attach_rtdb()` -> (shm, rtdb)
    2. Build `SignalResolver()` and validate config signal paths at startup. Log ERROR for unknown paths, set those rules' `enabled = False` (fail-open per CONTEXT.md)
    3. `build_alarm_instances(config)` -> instances dict
    4. `AlarmEvaluator(instances)` -> evaluator
    5. ZMQ Context + 3 sockets:
       - REP on `rep_endpoint or SOCK_ALARM_CMD` (LINGER=0)
       - PUSH connect to `push_endpoint or SOCK_LOGGER` (LINGER=0)
       - PUB bind on `pub_endpoint or SOCK_ALARM_PUB` (LINGER=0)
    6. `asyncio.Event()` for stop_event
    7. Extract signal paths list from config for resolve_all calls

    **_poll_commands():** Non-blocking REP drain (copy ControlLoop pattern verbatim):
    - `get_active_alarms` -> `evaluator.get_active_alarms()`
    - `acknowledge` -> `evaluator.acknowledge(params["alarm_id"])`, return result
    - `get_alarm_config` -> `evaluator.get_alarm_config()`
    - Unknown action -> error response
    - Wrap in try/except, ALWAYS send reply

    **_tick(now_ms):**
    1. Seqlock read BMS clusters (iterate `_seqlock_read_section(rtdb.clusters[c].racks[r])` for each rack) and PCS section
    2. Build a temporary RTDB-like object with the copied sections for the resolver
    3. `resolver.resolve_all(signal_paths, rtdb_copy)` -> values dict
    4. `evaluator.evaluate_tick(values, now_ms)` -> events list
    5. For each event: publish on PUSH (encode_event with source="alarm_manager", event_type=TOPIC_ALARM) and PUB (topic prefix b"alarm" + msgpack payload)
    6. Use `zmq.NOBLOCK` + catch `zmq.Again` for PUSH sends

    **Note on seqlock reads for BMS:** Each `EmsRack` has its own seqlock. Read each rack individually with `_seqlock_read_section()`. The resolver then operates on the copied rack data. For PCS, read `_seqlock_read_section(rtdb.pcs)` once.

    **Important:** Copy `_seqlock_read_section` function from ControlLoop (duplicate in loop.py, same as Phase 14 deferred refactor note). Do NOT import from ems_control_manager.

    **run():**
    ```python
    async def run(self) -> None:
        while not self._stop_event.is_set():
            tick_start = time.monotonic()
            self._poll_commands()
            now_ms = tick_start * 1000.0
            self._tick(now_ms)
            elapsed = time.monotonic() - tick_start
            await asyncio.sleep(max(0.0, 1.0 - elapsed))
    ```

    ```python
    """alarm_manager entry point — 1Hz IEC 62682 alarm evaluation engine."""
    from __future__ import annotations

    import argparse
    import asyncio
    import logging
    import signal
    from pathlib import Path

    from ems_alarm_manager.config import load_alarm_config
    from ems_alarm_manager.loop import AlarmLoop


    def parse_args() -> argparse.Namespace:
        parser = argparse.ArgumentParser(description="EMS Alarm Manager")
        parser.add_argument(
            "--config",
            type=Path,
            default=Path("config/alarms_config.yaml"),
            help="Path to alarms_config.yaml",
        )
        parser.add_argument(
            "--log-level",
            default="INFO",
            choices=["DEBUG", "INFO", "WARNING", "ERROR"],
            help="Logging level",
        )
        return parser.parse_args()


    async def run(args: argparse.Namespace) -> None:
        logging.basicConfig(
            level=getattr(logging, args.log_level),
            format="%(asctime)s %(name)s %(levelname)s %(message)s",
        )
        config = load_alarm_config(args.config)
        loop_obj = AlarmLoop(config)
        asyncio_loop = asyncio.get_running_loop()

        def _signal_handler() -> None:
            loop_obj.stop_event.set()

        for sig in (signal.SIGTERM, signal.SIGINT):
            asyncio_loop.add_signal_handler(sig, _signal_handler)

        try:
            await loop_obj.run()
        finally:
            loop_obj.cleanup()


    def main() -> None:
        args = parse_args()
        asyncio.run(run(args))


    if __name__ == "__main__":
        main()
    ```
