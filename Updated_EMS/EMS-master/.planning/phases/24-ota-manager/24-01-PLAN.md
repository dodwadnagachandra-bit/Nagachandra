    1. Create downloader.py (src/ota_manager/src/ems_ota_manager/downloader.py):
       - class HttpDownloader:
         - __init__(self, staging_dir: Path, max_package_mb: int = 500, chunk_size: int = 65536, timeout_s: float = 300.0)
         - async download(self, url: str, dest_filename: str, expected_sha256: str, on_progress: Callable[[int, int], None] | None = None) -> Path
           - Creates staging_dir if not exists (mkdir parents=True)
           - dest = staging_dir / dest_filename; partial = dest.with_suffix(".partial")
           - Resume: if partial exists, read its size, set Range header, pre-hash existing bytes
           - httpx.AsyncClient.stream("GET", url, headers=headers, follow_redirects=True, timeout=timeout_s)
           - Check Content-Length + resume_from <= max_package_mb * 1024 * 1024, raise ValueError if exceeded
           - Stream chunks with aiter_bytes(chunk_size), update sha256, call on_progress
           - After stream complete: verify sha256.hexdigest() == expected_sha256
           - On match: partial.rename(dest), return dest
           - On mismatch: partial.unlink(missing_ok=True), raise ValueError with expected vs actual hash
         - cleanup_staging(self) -> None — removes all files in staging_dir
