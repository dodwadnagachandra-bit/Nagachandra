Create a comprehensive pytest integration test module that starts the safety_manager binary with `--rtdb-backend` and validates all safety behaviors through the RTDB.

**Test infrastructure (fixtures):**
- `@pytest.fixture` `rtdb_shm`: Creates RTDB shared memory via `create_rtdb()` with minimal topology (1,1,1,1,1). Yields the ctypes pointer. Tears down via `detach_rtdb()` + unlink on cleanup.
- `@pytest.fixture` `gpio_harness(rtdb_shm)`: Creates RtdbBackend instance from rtdb_shm pointer. Provides `set_di`, `set_di_multi`, `get_do`, `get_do_all` methods.
- `@pytest.fixture` `safety_process(rtdb_shm)`: Starts `safety_manager` binary via `subprocess.Popen` with `--rtdb-backend --no-watchdog --scan-interval-ms 5`. Waits 100ms for startup. Yields process. On teardown: sends SIGTERM, waits 2 seconds, kills if needed.
- `@pytest.fixture` `zmq_subscriber`: Creates ZMQ SUB socket connecting to `tcp://127.0.0.1:15555` (or test-specific telemetry address passed via env var to safety_manager). Subscribes to "gpio" topic. Yields socket. Closes on teardown.
- `@pytest.fixture` `zmq_reset_client`: Creates ZMQ REQ socket connecting to safety reset address. Yields socket.
- Helper: `wait_for_do(harness, index, expected_value, timeout_ms=500)` -- polls `get_do(index)` until value matches or timeout. Returns elapsed time in ms.
- Helper: `wait_for_do_mask(harness, expected_mask, timeout_ms=500)` -- waits until all 8 DOs match the expected bitmask.

**Test cases (one per requirement, some requirements have multiple tests):**

SAFE-01 (E-Stop dual-channel):
- `test_estop_dual_channel_triggers`: Set DI-6=1 (NO high) and DI-7=0 (NC low, active_low inverts to logical high). Verify DO-0, DO-4, DO-5, DO-6 all assert within 200ms. DO-3 (running) is OFF.
- `test_estop_single_channel_discrepancy`: Set DI-6=1, DI-7=1 (both raw high -- NC channel not inverted means NC NOT pressed). Verify E-Stop outputs are NOT asserted. This is a wiring fault -- the DI values are published to RTDB but no protective action taken.
- `test_estop_no_channel_only`: Set DI-6=1, DI-7=1 (DI-7 raw high = NC channel idle). Verify no E-Stop response.

SAFE-02 (E-Stop response timing):
- `test_estop_response_within_100ms`: Measure time from `set_di_multi({6: 1, 7: 0})` to DO-5 (PCS_STOP) asserting. Assert elapsed < 100ms. Run 10 iterations, assert max < 100ms.

SAFE-03 (Fire dual-confirm):
- `test_fire_dual_confirm_triggers`: Set DI-3=1, DI-4=1. Verify DO-1 (extinguisher) + DO-0, DO-4, DO-5, DO-6 all assert.
- `test_fire_single_sensor_no_extinguisher`: Set DI-3=1 only. Verify DO-1 (extinguisher) is NOT asserted. DO-2 (warning) may be asserted.

SAFE-04 (Flood):
- `test_flood_triggers_outputs`: Set DI-1=1. Verify DO-0 (ACDB trip), DO-4 (fault), DO-5 (PCS stop), DO-6 (siren) assert. DO-1 (extinguisher) is NOT asserted.

SAFE-05 (Watchdog -- tested indirectly):
- `test_process_stays_alive`: Start safety_manager without --no-watchdog on a system that has /dev/watchdog (skip if not available). Verify process is still running after 5 seconds. If /dev/watchdog not available, skip test with `pytest.mark.skipif`.
- Note: Full watchdog testing requires hardware. The C unit tests for watchdog logic validate the condvar pattern.

SAFE-06 (SCHED_FIFO):
- `test_rt_priority_set`: Start safety_manager. Read `/proc/{pid}/sched` or use `os.sched_getscheduler(pid)` to verify SCHED_FIFO is set (may need root). If not root, verify process starts without error (graceful fallback).

SAFE-07 (Watchdog thread priority):
- `test_watchdog_thread_exists`: Start safety_manager without --no-watchdog (if /dev/watchdog available). Check /proc/{pid}/task/ for multiple threads. Verify at least 2 threads exist. Skip if /dev/watchdog unavailable.

SAFE-08 (RTDB GPIO writes):
- `test_rtdb_di_values_updated`: Set DI-3=1 via harness. Wait 100ms. Read rtdb->gpio.di[3] directly via ctypes. Verify it reflects the input.
- `test_rtdb_do_state_updated`: Trigger E-Stop. Wait 100ms. Read rtdb->gpio.do_state[5] (PCS stop). Verify it is 1.
- `test_rtdb_last_update_ms_advancing`: Read rtdb->gpio.last_update_ms. Wait 50ms. Read again. Verify it increased.

SAFE-09 (ZMQ events):
- `test_zmq_event_on_estop`: Subscribe to ZMQ telemetry. Trigger E-Stop. Receive message within 1 second. Decode MessagePack envelope. Verify event_type contains "estop" or "output_asserted", source is "safety_manager", topic is "gpio".

SAFE-10 (Independent lifecycle):
- `test_starts_without_config_manager`: Start safety_manager without config_manager running. Verify process starts (uses compiled defaults or file fallback). Verify process is alive after 2 seconds.
- `test_starts_without_data_manager`: Start safety_manager with RTDB not created (remove shm first). Verify process starts and handles missing RTDB gracefully (logs error, continues).

SAFE-11 (GPIO failure):
- `test_gpio_failure_asserts_all`: This is tested via the response matrix C unit tests. For integration, if the RTDB backend can simulate read failure (return -1), trigger it and verify all outputs assert. Otherwise, verify via C unit test results.

**General tests:**
- `test_clean_shutdown`: Send SIGTERM. Verify process exits within 2 seconds with returncode 0. Verify DO outputs are all de-asserted (check RTDB).
- `test_latching_requires_reset`: Trigger E-Stop. Clear inputs. Verify outputs remain asserted (latched). Send safety_reset via ZMQ. Verify outputs clear.
- `test_reset_rejected_while_active`: Trigger E-Stop (inputs still active). Send safety_reset. Verify response status is "error".
- `test_normal_state_running_lamp`: All inputs normal. Verify DO-3 (running lamp) is ON, all other DOs OFF.

**Test configuration:**
- Use `tcp://127.0.0.1` addresses for ZMQ sockets (not ipc://) to avoid /run/ems dependency.
- Pass ZMQ addresses to safety_manager via environment variables or CLI args (e.g., `--telemetry-addr tcp://127.0.0.1:15555 --logger-addr tcp://127.0.0.1:15556 --reset-addr tcp://127.0.0.1:15557`).
- Each test function should use a unique port range or let the OS pick ports to avoid conflicts.
- Use the binary path from the cmake build directory: `build/src/safety_manager/safety_manager`.
